以下是问题建模与MATLAB实现思路的完整转换：

---

### **1. 建模数学公式**

这是一个典型的**流固耦合问题**，采用**准静态水动力模型**进行简化分析。以下是核心方程：

#### **1.1 坐标系与运动学**

- **全局坐标系 (O-xy)**：
  - x轴：沿河流方向，逆流而上为正。
  - y轴：垂直于河流方向（船体摇晃方向）。

- **船体运动**：
  - 逆流速度：$ V_x(t) $
  - 逆流位置：$ x(t) = \int_0^t V_x(\tau) \, d\tau $
  - 船夫施加的摇晃速度（简谐运动）：  
    $$
    V_{\text{sway}}(t) = A\omega \cos(\omega t)
    $$  
    其中 $ A $ 为振幅，$ \omega = 2\pi f $ 为角频率。
  - 船体总速度向量：  
    $$
    \vec{V}_{\text{boat}}(t) = [V_x(t), \, V_{\text{sway}}(t)]
    $$

- **水流速度**：
  - 恒定水流速度：  
    $$
    \vec{V}_{\text{current}} = [-V_c, \, 0]
    $$

- **相对速度**（关键物理量）：
  - 相对速度向量：  
    $$
    \vec{V}_{\text{rel}}(t) = \vec{V}_{\text{boat}}(t) - \vec{V}_{\text{current}} = [V_x(t) + V_c, \, V_{\text{sway}}(t)]
    $$
  - 相对速度大小：  
    $$
    V_{\text{rel}}(t) = \sqrt{(V_x(t) + V_c)^2 + V_{\text{sway}}(t)^2}
    $$

---

#### **1.2 水动力学**

当船体与水流存在相对运动时，产生升力和阻力：

- **有效攻角 $ \alpha(t) $**：
  $$
  \alpha(t) = \text{atan2}(V_{\text{sway}}(t), V_x(t) + V_c)
  $$

- **升力 $ F_L $ 与阻力 $ F_D $**：
  $$
  F_L(t) = \frac{1}{2} \rho V_{\text{rel}}(t)^2 S C_L(\alpha)
  $$
  $$
  F_D(t) = \frac{1}{2} \rho V_{\text{rel}}(t)^2 S C_D(\alpha)
  $$
  其中：
  - $ \rho $：水的密度。
  - $ S $：船体水下侧面积（$ S = L_{\text{boat}} \times H_{\text{draft}} $）。
  - $ C_L(\alpha), C_D(\alpha) $：升力系数与阻力系数（攻角函数）。

- **升阻力系数简化模型**：
  $$
  C_L(\alpha) \approx C_{L\alpha} \sin(\alpha) \cos(\alpha)
  $$
  $$
  C_D(\alpha) \approx C_{D0} + C_{Di} \sin^2(\alpha)
  $$
  其中 $ C_{L\alpha}, C_{D0}, C_{Di} $ 为船型相关常数。

---

#### **1.3 动力学方程**

将升力和阻力投影到全局坐标系，建立运动方程：

- **力的分解**：
  - 相对速度方向与x轴夹角 $ \beta(t) = \alpha(t) $
  - x方向合力：  
    $$
    F_x(t) = -F_D \cos(\alpha) + F_L \sin(\alpha)
    $$
  - y方向合力：  
    $$
    F_y(t) = -F_D \sin(\alpha) - F_L \cos(\alpha)
    $$

- **牛顿第二定律**：
  - 仅关注x方向运动（y方向为强制摇晃）：  
    $$
    m \frac{dV_x}{dt} = F_{\text{net},x}
    $$
  - 最终ODE方程：  
    $$
    \frac{dV_x}{dt} = \frac{1}{m} \left[ -F_D(t) \cos(\alpha(t)) + F_L(t) \sin(\alpha(t)) \right]
    $$
  - 方程需通过数值方法求解，因为 $ F_D, F_L, \alpha $ 均依赖 $ V_x(t) $ 和时间 $ t $。

---


### 第二部分：MATLAB 建模模拟思路

我们将使用MATLAB强大的ODE求解器（如 `ode45`）来求解上述常微分方程。

#### **步骤 1: 定义系统参数**

首先，在一个脚本文件（例如 `main_boat_sim.m`）中定义所有常量。

```matlab
% --- 物理和几何参数 ---
rho = 1000;         % 水的密度 (kg/m^3)
m = 200;            % 船和船夫的总质量 (kg)
L_boat = 5;         % 船长 (m)
H_draft = 0.3;      % 吃水深度 (m)
S = L_boat * H_draft; % 有效侧面积 (m^2)
Vc = 1.0;           % 水流速度 (m/s)

% --- 摇晃运动参数 ---
f = 0.5;            % 摇晃频率 (Hz)
A = 0.4;            % 摇晃单侧振幅 (m)
omega = 2 * pi * f; % 角频率 (rad/s)

% --- 水动力系数 (估算值) ---
CL_alpha = 2.0;     % 升力系数斜率 (估算)
CD0 = 0.05;         % 零升力阻力系数 (估算)
CDi = 0.5;          % 诱导阻力系数 (估算)
```

#### **步骤 2: 创建ODE函数**

创建一个独立的函数文件（例如 `boat_dynamics.m`），该函数将根据当前的**时间 `t`** 和**状态 `state`** 来计算状态的导数。`ode45` 会反复调用这个函数。

```matlab
function d_state_dt = boat_dynamics(t, state, params)
    % 解包状态变量
    % state(1) 是位置 x, state(2) 是速度 Vx
    x = state(1);
    Vx = state(2);
    
    % 从 params 结构体中解包参数
    rho = params.rho; S = params.S; Vc = params.Vc;
    A = params.A; omega = params.omega;
    CL_alpha = params.CL_alpha; CD0 = params.CD0; CDi = params.CDi;
    m = params.m;

    % 1. 计算当前时刻的运动学量
    V_sway = A * omega * cos(omega * t);
    
    % 2. 计算相对速度和攻角
    V_rel_x = Vx + Vc;
    V_rel_y = V_sway;
    V_rel = sqrt(V_rel_x^2 + V_rel_y^2);
    alpha = atan2(V_rel_y, V_rel_x);
    
    % 3. 计算升阻力系数
    CL = CL_alpha * sin(alpha) * cos(alpha);
    CD = CD0 + CDi * sin(alpha)^2;
    
    % 4. 计算升力和阻力大小
    F_L = 0.5 * rho * V_rel^2 * S * CL;
    F_D = 0.5 * rho * V_rel^2 * S * CD;
    
    % 5. 将力投影到全局x轴
    Fx_hydro = -F_D * cos(alpha) + F_L * sin(alpha);
    
    % 6. 计算x方向的加速度
    ax = Fx_hydro / m;
    
    % 7. 返回状态的导数
    % dx/dt = Vx
    % dVx/dt = ax
    d_state_dt = [Vx; ax];
end
```

*注意：为了方便传递大量参数，通常会将参数放入一个结构体 `params` 中。*

#### **步骤 3: 调用ODE求解器并可视化**

回到主脚本 `main_boat_sim.m`，设置初始条件，调用 `ode45`，然后绘制结果。

```matlab
% (接步骤1的代码)

% 将参数打包成结构体
params.rho = rho; params.S = S; ... % (省略所有参数的赋值)
params.m = m;

% --- 仿真设置 ---
t_span = [0, 60]; % 仿真时间范围 (0到60秒)
initial_conditions = [0; 0]; % 初始位置x=0, 初始速度Vx=0

% --- 调用 ode45 求解 ---
% @(t, state) boat_dynamics(t, state, params) 创建一个匿名函数
% 这样 ode45 就可以调用我们带有三个参数的函数了
[t_sol, state_sol] = ode45(@(t, state) boat_dynamics(t, state, params), t_span, initial_conditions);

% --- 结果后处理与可视化 ---
x_sol = state_sol(:, 1);
Vx_sol = state_sol(:, 2);

% 绘制速度-时间曲线
figure;
plot(t_sol, Vx_sol, 'b-', 'LineWidth', 2);
xlabel('时间 (s)');
ylabel('逆流速度 Vx (m/s)');
title('小船逆流速度随时间的变化');
grid on;
hline = refline(0, 0); % 添加 y=0 参考线
hline.Color = 'k';

% 绘制位置-时间曲线
figure;
plot(t_sol, x_sol, 'r-', 'LineWidth', 2);
xlabel('时间 (s)');
ylabel('逆流位置 x (m)');
title('小船逆流位置随时间的变化');
grid on;

% 如果平均速度为正，说明成功实现了逆水行舟！
avg_Vx = mean(Vx_sol(t_sol > 30)); % 计算后半段的平均速度
fprintf('仿真结束，后半段平均逆流速度为: %.3f m/s\n', avg_Vx);
```

通过运行这个模型，你就可以观察在设定的参数下，船的平均速度是否大于零，从而判断“逆水行舟”是否成功。你还可以通过修改摇晃频率`f`、振幅`A`等参数，来寻找最优的推进策略。
