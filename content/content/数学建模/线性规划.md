线性规划
- 背景：
一个家具厂可以生产桌子和椅子两种产品。生产一张桌子需要2个单位的木材和4小时的工时，利润为80元。生产一把椅子需要1个单位的木材和2小时的工时，利润为50元。该工厂每周最多能获得100个单位的木材和180小时的工时。工厂希望合理安排生产计划，以获得最大利润。

- 数学方程：
1. 决策变量：
- 设 $x_1$ 为每周生产桌子的数量。
- 设 $x_2$ 为每周生产椅子的数量。
2. 目标函数 (最大化利润)：
- Maximize $Z = 80x_1 + 50x_2$
3. 约束条件:
- 木材约束: $2x_1 + 1x_2 \leq 100$
- 工时约束: $4x_1 + 2x_2 \leq 180$
- 非负约束: $x_1 \geq 0, x_2 \geq 0$ (产量不能为负)


```python
import coptpy as cp
from coptpy import COPT

# 1. 创建模型
env = cp.Envr()
model = env.createModel("FurnitureFactory")

# 2. 创建决策变量
# x1: 每周生产桌子的数量
# x2: 每周生产椅子的数量
x1 = model.addVar(name="x1", vtype=COPT.CONTINUOUS, lb=0)
x2 = model.addVar(name="x2", vtype=COPT.CONTINUOUS, lb=0)

# 3. 设置目标函数
# maximize Z = 80*x1 + 50*x2
model.setObjective(80 * x1 + 50 * x2, COPT.MAXIMIZE)

# 4. 添加约束条件
# 木材约束: 2*x1 + x2 <= 100
model.addConstr(2 * x1 + x2 <= 100, name="wood")

# 工时约束: 4*x1 + 2*x2 <= 180
model.addConstr(4 * x1 + 2 * x2 <= 180, name="labor")

# 5. 求解模型
model.solve()

# 6. 打印结果
if model.status == COPT.OPTIMAL:
    print("找到了最优解！")
    print(f"最大利润为: {model.objval:.2f} 元")
    print("生产计划如下:")
    print(f"  - 生产桌子: {x1.x:.0f} 张")
    print(f"  - 生产椅子: {x2.x:.0f} 把")
else:
    print("未找到最优解。")
```
