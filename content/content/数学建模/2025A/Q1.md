### **问题1 详细求解思路**

**核心目标：** 计算一个动态几何问题中的有效遮蔽总时长。即在烟幕云团存在的20秒内，有多少时间它能成功阻挡M1导弹到真目标的视线。

**求解步骤可以清晰地分解为以下六步：**

#### **第一步：确定所有对象的初始状态和运动方程**

我们需要用数学语言描述M1导弹和FY1无人机的运动。
1.  **M1导弹:**
    * 初始位置：$P_{M1}(0) = (20000, 0, 2000)$
    * 目标点（假目标）：$P_{FT} = (0, 0, 0)$
    * 速度大小：$v_{M1} = 300 \ m/s$
    * 方向向量（单位向量）：$\vec{d}_{M1} = \frac{P_{FT} - P_{M1}(0)}{||P_{FT} - P_{M1}(0)||}$
    * **任意时刻 `t` 的位置方程：** $P_{M1}(t) = P_{M1}(0) + \vec{d}_{M1} \cdot v_{M1} \cdot t$

2.  **FY1无人机:**
    * 初始位置：$P_{FY1}(0) = (17800, 0, 1800)$
    * 飞行方向：朝向假目标，由于是等高飞行，我们只看xy平面的方向。方向向量为 $\vec{d}_{FY1} = (-1, 0, 0)$。
    * 速度大小：$v_{FY1} = 120 \ m/s$
    * **任意时刻 `t` 的位置方程：** $P_{FY1}(t) = P_{FY1}(0) + \vec{d}_{FY1} \cdot v_{FY1} \cdot t$

3.  **真目标:**
    * 这是一个静止的圆柱体。为简化计算，我们首先关注其**中心轴**和**几何中心**。
    * 中心轴：连接点 $(0, 200, 0)$ 和 $(0, 200, 10)$ 的线段。
    * 几何中心（近似代表点）：$P_T = (0, 200, 5)$

#### **第二步：计算烟幕弹的投放点和起爆点**

这是两次关键的“状态转移”。
1.  **投放点 ($P_{drop}$):**
    * 投放时间：$t_{drop} = 1.5 \ s$
    * 投放点位置即为无人机在1.5s时的位置：$P_{drop} = P_{FY1}(1.5)$
    * 投放瞬间，烟幕弹的初速度继承自无人机：$\vec{v}_{bomb\_initial} = \vec{d}_{FY1} \cdot v_{FY1} = (-120, 0, 0) \ m/s$

2.  **起爆点 ($P_{det}$):**
    * 起爆时间：$t_{det} = 1.5 s + 3.6 s = 5.1 \ s$
    * 烟幕弹在空中飞行时间：$\Delta t_{flight} = 3.6 \ s$
    * 此过程为**平抛运动**。使用物理公式计算位移：
        * 水平位移：$\Delta P_{xy} = \vec{v}_{bomb\_initial} \cdot \Delta t_{flight}$
        * 垂直位移：$\Delta P_z = -\frac{1}{2} g (\Delta t_{flight})^2$ (其中 $g \approx 9.8 \ m/s^2$)
    * **起爆点位置：** $P_{det} = P_{drop} + (\Delta P_{xy,x}, \Delta P_{xy,y}, \Delta P_z)$

#### **第三步：建立烟幕云团的运动模型**

1.  **云团出现时间窗口：**
    * 起始：$t_{start} = t_{det} = 5.1 \ s$
    * 结束：$t_{end} = 5.1 s + 20 s = 25.1 \ s$
    * 我们需要检查导弹是否在此时间窗口内已击中目标。导弹飞行总时长 $T_{impact} = ||P_{M1}(0)|| / v_{M1}$。实际的分析窗口是 $[5.1, \min(25.1, T_{impact})]$。

2.  **云团中心位置方程：**
    * 云团以 $3 \ m/s$ 匀速下沉。
    * 对于任意时刻 $t \in [t_{start}, t_{end}]$，云团中心位置为：
        $P_C(t) = P_{det} - (0, 0, 3 \cdot (t - t_{start}))$

#### **第四步：定义“有效遮蔽”的几何判断准则**

这是模型的核心。我们采用一个合理且计算可行的简化准则。
* **准则：** 在时刻`t`，如果**导弹位置 $P_{M1}(t)$** 与**真目标中心 $P_T$** 的连线段，与以**云团中心 $P_C(t)$** 为球心、半径 $R_c = 10 \ m$ 的球体相交，则认为该时刻是有效遮蔽的。
* **数学转换：** 该准则等价于：计算云团中心点 $P_C(t)$ 到线段 $P_{M1}(t)P_T$ 的**最短距离** $d_{min}$。如果 $d_{min} \le R_c$，则遮蔽成立。

#### **第五步：进行时域离散化仿真**

我们无法解析地求解总时长，因此采用数值模拟。
1.  **设定时间步长：** 选择一个足够小的时间步长，例如 $\Delta t = 0.01 \ s$。
2.  **初始化计时器：** `TotalShieldingTime = 0`。
3.  **循环计算：**
    * `For t from 5.1 to min(25.1, T_impact) step Δt:`
        1.  **计算动态位置：**
            * 用 M1 的位置方程计算 $P_{M1}(t)$。
            * 用云团中心的位置方程计算 $P_C(t)$。
        2.  **执行几何判断：**
            * 计算点 $P_C(t)$ 到线段 $P_{M1}(t)P_T$ 的最短距离 $d_{min}$。
            * `If d_min <= 10:`
                * `TotalShieldingTime = TotalShieldingTime + Δt`

#### **第六步：输出最终结果**

循环结束后，`TotalShieldingTime` 的值即为所求的“有效遮蔽时长”。

---
这个六步法将问题分解为一系列明确、可计算的子任务，从建立运动学模型到确定关键事件点，再到构建判断准则并最终通过数值模拟求解，构成了一条完整的、逻辑严谨的解决路径。
