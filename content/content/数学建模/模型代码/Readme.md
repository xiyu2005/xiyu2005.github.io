先在总体文件夹下创建并激活虚拟环境
python3 -m venv myenv
source myenv/bin/activate
再安装依赖
pip install -r requirements.txt
然后在虚拟环境下运行即可。
Q1.py为第一小问的代码（运行小于1min）
Q2.py为第二小问的代码（运行约2min）
Q_sensitivity_error_analysis.py为第三小问的代码（运行时间约1min）
problem1_results_risk_calc为第一题结果
问题2分析结果为第二题结果
灵敏度与误差分析结果为第三题结果
