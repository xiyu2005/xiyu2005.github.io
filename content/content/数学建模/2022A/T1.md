好的，我们来逐步建立这个问题 richiesto 的数学模型。

### **波浪能装置垂荡运动数学模型**

#### **1. 问题简化与基本假设**

为了建立一个清晰的数学模型，我们首先做出以下基本假设：

1.  **单自由度运动**：系统只在垂直方向上运动（垂荡），不考虑任何旋转或其他方向的平动。
2.  **线性系统**：所有涉及的力（弹簧力、阻尼力、水动力等）都与位移或速度成线性关系。
3.  **刚体假设**：浮子和振子均为刚体。
4.  **小振幅波**：波浪是微幅波，其作用可以用线性波浪理论来描述。
5.  **忽略质量**：忽略中轴、弹簧和阻尼器自身的质量。

#### **2. 参数设定与变量定义**

我们设定以下参数来描述这个物理系统。在实际解题中，这些参数值将从附件中获取，但在这里我们用符号表示它们。

**a) 系统状态变量 (随时间 $t$ 变化):**

* $z_1(t)$: 浮子质心相对于其静水平衡位置的垂荡位移（向上为正）。
* $z_2(t)$: 振子质心相对于其静水平衡位置的垂荡位移（向上为正）。
* $\dot{z}_1(t), \ddot{z}_1(t)$: 分别为浮子的速度和加速度。
* $\dot{z}_2(t), \ddot{z}_2(t)$: 分别为振子的速度和加速度。

**b) 物理和几何参数 (常量):**

* $m_1$: 浮子的质量。
* $m_2$: 振子的质量。
* $k$: PTO系统中弹簧的刚度系数。
* $c$: PTO系统中直线阻尼器的阻尼系数。

**c) 水动力参数 (与波浪频率 $\omega$ 相关):**

* $m_a(\omega)$: 浮子的附加质量。这是由于浮子在水中加速运动时，必须同时加速周围的水体，等效于一个额外的质量。
* $\lambda(\omega)$: 兴波阻尼系数。这是由于浮子振荡会产生向外辐射的波浪，带走能量，从而对浮子运动产生阻尼作用。
* $C_1$: 静水恢复力系数。当浮子偏离平衡位置时，浮力的变化会使其有恢复到平衡位置的趋势。$C_1 = \rho g A_w$，其中 $\rho$ 是海水密度，$g$ 是重力加速度，$A_w$ 是浮体在静水面的水线面面积。

**d) 外部激励参数:**

* $F_{wave}(t)$: 波浪对浮子产生的激励力。通常简化为简谐力形式。
* $f(\omega)$: 波浪激励力的振幅。
* $\omega$: 入射波浪的圆频率。

因此，外部激励力可以表示为：$F_{wave}(t) = f(\omega) \cos(\omega t)$。

#### **3. 受力分析与模型建立**

我们分别对浮子和振子应用牛顿第二定律 ( $\sum F = ma$ )。

**a) 浮子 ($m_1$) 的受力分析:**

浮子在垂直方向上受到以下力的作用：
1.  **波浪激励力** $F_{wave}(t)$: 波浪施加的驱动力，方向向上或向下。
2.  **附加惯性力** $F_{add}$: 与浮子加速度方向相反，大小为 $-m_a \ddot{z}_1$。
3.  **兴波阻尼力** $F_{rad}$: 与浮子速度方向相反，大小为 $-\lambda \dot{z}_1$。
4.  **静水恢复力** $F_{hydro}$: 与浮子位移方向相反，大小为 $-C_1 z_1$。
5.  **弹簧力** $F_{spring}$: 由振子通过弹簧施加，大小为 $k(z_2 - z_1)$。
6.  **阻尼力** $F_{damper}$: 由振子通过阻尼器施加，大小为 $c(\dot{z}_2 - \dot{z}_1)$。

根据牛顿第二定律，浮子的运动方程为：
$$m_1 \ddot{z}_1 = F_{wave}(t) + F_{add} + F_{rad} + F_{hydro} + F_{spring} + F_{damper}$$
代入各项表达式：
$$m_1 \ddot{z}_1 = f \cos(\omega t) - m_a \ddot{z}_1 - \lambda \dot{z}_1 - C_1 z_1 + k(z_2 - z_1) + c(\dot{z}_2 - \dot{z}_1)$$
整理后得到**浮子的运动方程**:
$$(m_1 + m_a) \ddot{z}_1 + \lambda \dot{z}_1 + (C_1 + k) z_1 - k z_2 - c \dot{z}_2 = f \cos(\omega t)$$

**b) 振子 ($m_2$) 的受力分析:**

振子在垂直方向上受到以下力的作用（注意：重力与弹簧的初始预紧力在平衡位置相抵消，这里只考虑偏离平衡位置后的动态力）：
1.  **弹簧力** $-F_{spring}$: 由浮子（通过固定底座）施加，大小为 $-k(z_2 - z_1)$。
2.  **阻尼力** $-F_{damper}$: 由浮子（通过固定底座）施加，大小为 $-c(\dot{z}_2 - \dot{z}_1)$。

根据牛顿第二定律，振子的运动方程为：
$$m_2 \ddot{z}_2 = -k(z_2 - z_1) - c(\dot{z}_2 - \dot{z}_1)$$
整理后得到**振子的运动方程**:
$$m_2 \ddot{z}_2 + c \dot{z}_2 + k z_2 - k z_1 - c \dot{z}_1 = 0$$

#### **4. 最终的数学模型**

综上所述，该波浪能装置在只考虑垂荡运动时的数学模型，是一个由两个二阶线性常微分方程构成的耦合方程组：

$$
\begin{cases}
(m_1 + m_a) \ddot{z}_1 + \lambda \dot{z}_1 + (C_1 + k) z_1 - c \dot{z}_2 - k z_2 = f \cos(\omega t) \\
m_2 \ddot{z}_2 + c (\dot{z}_2 - \dot{z}_1) + k (z_2 - z_1) = 0
\end{cases}
$$

为了求解该方程组，还需要定义系统的**初始条件**。通常假设系统在初始时刻($t=0$)处于静止状态，即：
$$z_1(0) = 0, \quad \dot{z}_1(0) = 0$$
$$z_2(0) = 0, \quad \dot{z}_2(0) = 0$$

这个模型完整地描述了在外部波浪激励下，浮子和振子相互作用、相互影响的动力学行为。求解这个方程组，即可得到任意时刻 $t$ 浮子和振子的位移 $z_1(t)$ 和 $z_2(t)$，进而可以求出它们的速度。


# 数学物理模型的建立与求解

## 1. 参数整理与计算

首先，我们从附件3和附件4中提取所有相关的参数值。

**来自附件4的系统固有参数:**
* 浮子质量: $m_1 = 4866$ kg  
* 振子质量: $m_2 = 2433$ kg  
* 弹簧刚度: $k = 80000$ N/m  
* 海水密度: $\rho = 1025$ kg/m³  
* 重力加速度: $g = 9.8$ m/s²  
* 浮子底半径: $R = 1$ m  

**来自附件3的波浪与水动力参数 (针对 $\omega = 1.4005$ s⁻¹):**  
* 波浪圆频率: $\omega = 1.4005$ s⁻¹  
* 垂荡附加质量: $m_a = 1335.535$ kg  
* 垂荡兴波阻尼系数: $\lambda = 656.3616$ N·s/m  
* 垂荡激励力振幅: $f = 6250$ N  

**计算所需参数:**  
* **静水恢复力系数 ($C_1$)**:  
    $$C_1 = \rho g A_w = 1025 \times 9.8 \times \pi \times (1)^2 \approx 31557.298 \text{ N/m}$$

**模型总参数计算:**  
* 浮子等效总质量:  
    $$M_1 = m_1 + m_a = 4866 + 1335.535 = 6201.535 \text{ kg}$$  
* 浮子总刚度项:  
    $$K_1 = C_1 + k = 31557.298 + 80000 = 111557.298 \text{ N/m}$$

---

## 2. 数学物理模型的建立

### 情况 (1): 线性阻尼模型

**阻尼力表达式:**  
$$F_{damper} = c(\dot{z}_2 - \dot{z}_1) = 10000(\dot{z}_2 - \dot{z}_1)$$

**通用模型代入后:**  
$$
\begin{cases}
(m_1 + m_a) \ddot{z}_1 + \lambda \dot{z}_1 + (C_1 + k) z_1 - c \dot{z}_2 - k z_2 = f \cos(\omega t) \\
m_2 \ddot{z}_2 + c (\dot{z}_2 - \dot{z}_1) + k (z_2 - z_1) = 0
\end{cases}
$$

**具体数学模型:**  
$$
\begin{cases}
6201.535 \ddot{z}_1 + 656.3616 \dot{z}_1 + 111557.298 z_1 - 10000 \dot{z}_2 - 80000 z_2 = 6250 \cos(1.4005 t) \\
2433 \ddot{z}_2 + 10000 (\dot{z}_2 - \dot{z}_1) + 80000 (z_2 - z_1) = 0
\end{cases}
$$

---

### 情况 (2): 非线性阻尼模型

**阻尼力表达式:**  
$$F_{damper} = c_p |\dot{z}_2 - \dot{z}_1|^\alpha \cdot \text{sgn}(\dot{z}_2 - \dot{z}_1)$$  
其中符号函数定义为：  
$$
\text{sgn}(x) =
\begin{cases}
1, & \text{if } x > 0 \\
0, & \text{if } x = 0 \\
-1, & \text{if } x < 0
\end{cases}
$$

**代入参数后:**  
$$F_{damper} = 10000 |\dot{z}_2 - \dot{z}_1|^{0.5} \cdot \text{sgn}(\dot{z}_2 - \dot{z}_1)$$

**通用模型代入后:**  
$$
\begin{cases}
(m_1 + m_a) \ddot{z}_1 + \lambda \dot{z}_1 + C_1 z_1 + k(z_1 - z_2) - F_{damper} = f \cos(\omega t) \\
m_2 \ddot{z}_2 + k(z_2 - z_1) + F_{damper} = 0
\end{cases}
$$

**具体数学模型:**  
$$
\begin{cases}
6201.535 \ddot{z}_1 + 656.3616 \dot{z}_1 + 111557.298 z_1 - 80000 z_2 - 10000 |\dot{z}_2 - \dot{z}_1|^{0.5} \text{sgn}(\dot{z}_2 - \dot{z}_1) = 6250 \cos(1.4005 t) \\
2433 \ddot{z}_2 + 80000 (z_2 - z_1) + 10000 |\dot{z}_2 - \dot{z}_1|^{0.5} \text{sgn}(\dot{z}_2 - \dot{z}_1) = 0
\end{cases}
$$

## 3. 求解条件

**初始条件:**  
$$
z_1(0) = 0, \quad \dot{z}_1(0) = 0 \\
z_2(0) = 0, \quad \dot{z}_2(0) = 0
$$

**求解区间:**  
* 总时长: $T_{total} = 40 \times \frac{2\pi}{1.4005} \approx 179.45$ s

两个模型（线性ODE组、非线性ODE组）及初始条件构成了完整的数值仿真计算基础。
