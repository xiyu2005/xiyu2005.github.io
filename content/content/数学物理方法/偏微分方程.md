一、预备知识之偏微分方程

偏微分方程的基本形式可以表示为：$F(x, y, ..., u, u_x, u_y, ..., u_{xx}, u_{xy}, ...) = 0$，

方程的解：称$u$是方程的解，如果把$u(x, y, ...)$及其相应的偏导数带入偏微分方程中后，在$x, y, ...$空间的某个区域$\Omega$中方程关于这些变量恒等成立。

方程的阶：因变函数偏导数的最高阶数称为偏微分方程的阶。

线性偏微分方程：方程中因变函数及其各阶偏导数都是线性（一次）的，且系数仅依赖于自变量。

拉普拉斯方程：$\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} = 0$；泊松方程：$\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} = f(x, y, z)$；

亥姆霍兹方程：$\nabla^2 u + k^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} + k^2 u = 0$；

热传导方程：$\frac{\partial u}{\partial t} = \alpha \left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2}\right)$；波动方程：$\frac{\partial^2 u}{\partial t^2} = c^2 \left(\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2}\right)$；

（非）齐次偏微分方程值的是当自由项（不）为0的方程。
