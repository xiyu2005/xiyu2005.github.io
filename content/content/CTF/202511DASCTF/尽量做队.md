K='a1a60171273e74a6'

了从加密的Base64字符串中恢复原始数据，我们需要逆向执行加密过程。加密过程使用了一
个固定密钥 `K = 'a1a60171273e74a6'`，并采用逐字节异或操作（XOR）进行加密。每字节的
密钥索引为 `(i + 1) % 16`，其中 `i` 是当前字节的索引。

---


1. **Base64解码**：将加密后的Base64字符串解码为原始字节。
2. **转换为十六进制**：将这些字节转换为十六进制字符串。
3. **十六进制转字节**：将十六进制字符串转换回字节。
4. **逐字节异或**：使用密钥的对应索引进行异或操作，恢复原始数据。
5. **解码为字符串**：将恢复的字节转换为UTF-8字符串。

---


```python
import base64
import pandas as pd

def decrypt(encoded_str):
    """
    解密一个Base64编码的字符串，使用固定密钥 'a1a60171273e74a6'。
    返回解密后的UTF-8字符串。
    """
    K = 'a1a60171273e74a6'
    encoded_bytes = base64.b64decode(encoded_str)
    hex_str = encoded_bytes.hex()
    hex_bytes = bytes.fromhex(hex_str)
    res = b''

    for i in range(len(hex_bytes)):
        key_idx = (i + 1) % 16
        key_char = K[key_idx]
        res += bytes([hex_bytes[i] ^ ord(key_char)])

    return res.decode('utf-8')

def main():
    """
    主函数：读取CSV文件，解密每列内容，保存为新文件。
    """
    # 读取CSV文件
    df = pd.read_csv('input.csv')

    # 对每列应用解密函数
    for col in df.columns:
        df[col] = df[col].apply(decrypt)

    # 保存解密后的数据
    df.to_csv('output.csv', index=False)
    print("解密完成，已保存至 output.csv")

if __name__ == '__main__':
    main()
```

在RSA加密中，若已知两个密钥指数 $ e_1 $ 和 $ e_2 $，以及对应的密文 $ c_1 $ 和 $c_2$，并且这两个指数互质，我们可以利用扩展欧几里得算法找到它们的线性组合 $x$ 和
 $y$，使得 $x \cdot e_1 + y \cdot e_2 = 1$。根据RSA的数学原理，可以通过如下公
式恢复明文：

$$
m \equiv c_1^x \cdot c_2^y \mod n
$$

其中，$x$ 和 $y$ 是扩展欧几里得算法得到的系数。若 $x$ 或 $y$ 为负数，则需
要对它们进行调整，使用模逆元进行计算。

---

### **

1. **扩展欧几里得算法**：用于找到 $x$ 和 $y$，使得 $x \cdot e_1 + y \cdot e_2 = 1$。
2. **处理负指数**：
   - 若 $x <0$，则计算 $c_1$ 的模 $n$ 逆元 $\text{inv\_c1}$，然后计算 $\text{inv\_c1}^{-x} \mod n$。
   - 若 $y < 0$，则计算 $c_2$ 的模 $n$ 逆元 $\text{inv\_c2}$，然后计算 $\text{inv\_c2}^{-y} \mod n$。
1. **计算明文**：将 $c_1^x \mod n$ 和 $c_2^y \mod n$ 相乘，再模 $n$ 得到明文
 $m$。

---



```python
def extended_gcd(a, b):
    """
    扩展欧几里得算法，返回 (gcd(a, b), x, y)，使得 x * a + y * b = gcd(a, b)
    """
    if b == 0:
        return (a, 1, 0)
    else:
        g, x, y = extended_gcd(b, a % b)
        return (g, y, x - (a // b) * y)

def decrypt_rsa(e1, e2, c1, c2, n):
    """
    RSA 密文解密函数，使用 e1, e2 作为密钥指数，c1, c2 为密文，n 为模数
    """
    g, x, y = extended_gcd(e1, e2)
    
    if g != 1:
        return None  # e1 和 e2 不互质，无法解密

    # 处理 x 的负指数
    if x < 0:
        inv_c1 = pow(c1, -1, n)
        c1_part = pow(inv_c1, -x, n)
    else:
        c1_part = pow(c1, x, n)

    # 处理 y 的负指数
    if y < 0:
        inv_c2 = pow(c2, -1, n)
        c2_part = pow(inv_c2, -y, n)
    else:
        c2_part = pow(c2, y, n)

    # 计算明文
    m = (c1_part * c2_part) % n
    return m

# 示例
if __name__ == "__main__":
    e1 = 65537
    e2 = 10001
    c1 = 123456789
    c2 = 987654321
    n = 1234567890123456789

    m = decrypt_rsa(e1, e2, c1, c2, n)
    print("明文 m =", m)
    
    

m_hex = hex(m)[2:]

# 如果十六进制长度为奇数，前面补0

if len(m_hex) % 2 != 0:

m_hex = '0' + m_hex

flag_bytes = bytes.fromhex(m_hex)

print(f" 明文 (bytes 格式): {flag_bytes}")
```

为了从加密后的字节序列中恢复原始明文，我们需要模拟加密过程的逆操作。加密过程使用了
RC4算法的变体，其中密钥是 `'love'`，且密钥流的生成基于S数组的初始化和KSA（Key  Scheduling Algorithm）。

---

### 

1. **初始化 S 数组**：从 0 到 255 的整数。
2. **生成 K 数组**：使用密钥 `'love'`，对每个索引 i，取 `K[i] = ord(key[i % 
len(key)])`。
3. **执行 KSA**：根据公式 `j = (j + S[i] + K[i]) % 256` 修改 S 数组。
4. **生成密钥流**：在 PRGA（Pseudo-Random Generation Algorithm）阶段，按顺序生成密
钥流。
5. **异或密钥流**：将密文 `t` 中的每个字节与对应的密钥流字节异或，恢复明文。

---

### 代码实现

```python
t = [164, 34, 242, 5, 234, 79, 16, 182, 136, 117, 78, 78, 71, 168, 72, 79, 53, 
114, 117]

# 初始化 S 数组
S = list(range(256))
key = 'love'
K = [0] * 256

# 生成 K 数组
for i in range(256):
    K[i] = ord(key[i % len(key)])

# 执行 KSA
j = 0
for i in range(256):
    j = (j + S[i] + K[i]) % 256
    S[i], S[j] = S[j], S[i]

# 生成密钥流
i, j = 0, 0
key_stream = []
for k in range(len(t)):
    i = (i + 1) % 256
    j = (j + S[i]) % 256
    S[i], S[j] = S[j], S[i]
    key_stream.append(S[(S[i] + S[j]) % 256])

# 异或密钥流恢复明文
plaintext = [t[k] ^ key_stream[k] for k in range(len(t))]

# 将字节转换为字符串
plaintext_str = ''.join([chr(c) for c in plaintext])

print(plaintext_str)
```

```python
# -*- coding: utf-8 -*-
import sys
from mnemonic import Mnemonic
from eth_account import Account

# 启用 HD Wallet 功能，这是从助记词派生所必需的
Account.enable_unaudited_hdwallet_features()

def find_mnemonic_by_suffix():
    """
    根据已知的部分助记词和地址后缀，爆破查找缺失的单词。
    """
    # 1. 设置已知信息
    # 使用 None 作为缺失单词的占位符
    known_parts = ["ankle", "assume", "estate", "permit", None, "eye", "fancy", "spring", "demand", "dial", "awkward", "hole"]
    missing_word_index = 4
    
    # 目标地址后缀（已转换为小写，以便于不区分大小写的比较）
    target_suffix = "700f80".lower()
    
    # 标准的以太坊派生路径
    derivation_path = "m/44'/60'/0'/0/0"

    # 2. 加载官方词库
    mnemo = Mnemonic("english")
    wordlist = mnemo.wordlist
    
    print("开始爆破查找缺失的单词...")
    print(f"目标地址后缀: ...{target_suffix}")

    # 3. 遍历词库中的每一个单词
    for i, word in enumerate(wordlist):
        current_mnemonic_list = known_parts.copy()
        current_mnemonic_list[missing_word_index] = word
        candidate_mnemonic = " ".join(current_mnemonic_list)
        
        # 打印单行刷新的进度条
        sys.stdout.write(f"\r进度: [{i+1}/{len(wordlist)}] 正在尝试: {word:<10}")
        sys.stdout.flush()

        # 4. 校验和检查（高效的过滤器）
        if not mnemo.check(candidate_mnemonic):
            continue  # 如果校验和无效，立即测试下一个单词

        # --- 如果代码能执行到这里，说明找到了一个校验和有效的助记词 ---
        print(f"\n[!] 发现有效助记词: '{candidate_mnemonic}'，正在派生地址...")

        # 5. 派生地址
        account = Account.from_mnemonic(candidate_mnemonic, account_path=derivation_path)
        derived_address = account.address
        
        # 6. 后缀比对
        if derived_address.lower().endswith(target_suffix):
            # 7. 找到答案！
            print(f"[-] 完整的助记词是: {candidate_mnemonic}")
            print(f"[-] 完整的钱包地址是: {derived_address}")
 
            return  # 任务完成，退出函数

    print("\n\n搜索完成，但未找到匹配的单词。")


if __name__ == "__main__":
    find_mnemonic_by_suffix()
```
