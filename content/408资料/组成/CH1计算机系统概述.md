# （一）计算机系统层次结构
## 1.计算机系统基本组成
- **完整系统 = 硬件 + 软件**。软件分为：
    - **系统软件**：操作系统、语言处理程序（汇编、编译、解释）、数据库管理系统、服务性程序；
    - **应用软件**：文字处理、浏览器、播放器等。
- **冯·诺依曼五大部件**：运算器、控制器、存储器、输入设备、输出设备；**主机 = CPU + 主存**。
- 程序运行时的**指令和数据存放在主存**；外存只是后备存储，程序启动后才装入内存。
- 存储器**既存指令又存数据**，两者均按地址访问。与哈佛结构（指令与数据分开存储）区分。

## 2.计算机硬件的基本结构
**CPU = 运算器 + 控制器 + 寄存器组**，不包括主存，也不包括地址译码器（地址译码器在主存中）。

| 部件  | 组成与功能                                          |
| --- | ---------------------------------------------- |
| 运算器 | ALU、通用寄存器、状态寄存器（PSW）、暂存器；完成**算术和逻辑运算**；不含地址寄存器 |
| 控制器 | 取指、**译码**、执行、访存、写回；统一指挥各部件                     |
| 主存  | 存储单元 + 地址译码器，按地址随机访问                           |
|     |                                                |

**核心寄存器**

- **PC**：下一条要执行指令的地址。若指令按字边界对齐存放，PC位数可以存储IR高位，一条指令后至少+1即可。
- **IR**：当前正在执行的指令；IR位数 = 指令字长。
- **MAR**位数=log2(主存单元总数)；**MDR**位数=存储字长；
- 通用寄存器：暂存操作数与结果；PSW：存放状态标志。


组合逻辑与时序逻辑电路
组合逻辑元件（操作元件）
**特点：** 输出仅由当前输入决定，**无记忆功能**。

| 类别        | 典型元件                                |
| --------- | ----------------------------------- |
| **基本门电路** | 与门、或门、非门、与非门、或非门、异或门、同或门            |
| **编码/译码** | 编码器、优先编码器、译码器                       |
| **数据选择**  | 多路选择器（MUX）、多路分配器（DEMUX）             |
| **运算部件**  | 全加器、行波进位加法器、先行进位加法器、进位选择加法器、ALU、比较器 |
| **信号驱动**  | 三态门、缓冲器                             |
| **其他**    | 组合逻辑控制器（硬布线控制器）                     |

> 数据通路中的 ALU、MUX、加法器、译码器都属于**操作元件**。

时序逻辑元件（状态元件）
**特点：** 输出不仅取决于当前输入，还取决于**历史状态**，具有记忆功能。

| 类别        | 典型元件                                |
| --------- | ----------------------------------- |
| **触发器**   | SR 触发器、D 触发器、JK 触发器、T 触发器           |
| **锁存器**   | 电平触发锁存器                             |
| **寄存器**   | 通用寄存器（GPRs）、PC、IR、MAR、MDR、PSW/FLAGS |
| **计数器**   | 程序计数器、循环计数器                         |
| **移位寄存器** | 串行/并行移位寄存器                          |
| **存储阵列**  | SRAM、DRAM、ROM（数据体 + 地址译码）           |
| **微程序控制** | 控制存储器 CM、微指令寄存器 μIR、微地址寄存器 μPC      |
## 3.计算机软件和硬件的关系
- **层次结构（自顶向下）**：高级语言虚拟机 → 汇编语言虚拟机 → 操作系统虚拟机 → 机器语言机器（硬件）。
- **ISA（指令集体系结构）**：软硬件的交界面，是低级语言程序员可见的机器属性，包括：
    - 指令格式、操作码、寻址方式；
    - 寄存器的数量、编号、长度、功能；
    - 数据类型与格式、寻址空间、中断/异常机制等。
- **微体系结构**：ISA 的硬件实现方案（流水线、超标量、ALU 电路、Cache 组织等）。
    - 同一 ISA 可有**多种微体系结构**；
    - 对程序员**透明**，影响性能但**不改变 ISA**。
- **语言与机器的关系**：机器语言、汇编语言**与机器结构相关**；高级语言与机器无关。**只有机器语言程序能被硬件直接执行**。
- 软硬件在逻辑功能上等价、可相互替代，二者界面即 ISA。
## 4.计算机系统的工作原理
**“存储程序”工作方式**
- 程序和数据均以**二进制**表示，**一起预先存入存储器**，形式上无差别；
- **按地址访问**，控制器自动、按序取指并执行（程序控制）；
- **区分指令与数据的依据**：不是存储形式，而是 **CPU 所处的指令周期阶段**（取指周期取指令、执行周期取数据）及地址来源（PC / 指令地址码）；
- 指令 = **操作码 + 地址码**；数据**不一定**在指令中直接给出（立即数只是寻址方式之一），数据同样按地址访问；
- “边输入边执行”“程序从磁盘直接到 CPU 执行”均**不是**冯·诺依曼特点。
**高级语言程序与机器语言程序之间的转换**

| 程序   | 特点                           |
| ---- | ---------------------------- |
| 机器语言 | 二进制，**唯一可硬件直接执行**            |
| 汇编语言 | 助记符，与机器结构相关；由**汇编程序**翻译成机器语言 |
| 高级语言 | 与机器无关；经**编译程序**或**解释程序**转换   |
- **编译程序**：一次性翻译，生成目标代码，编译时间长、**运行速度快**；
- **解释程序**：逐条翻译、翻译一条立即执行，不生成目标文件，**运行速度慢**、交互性好；
- **完整转换过程**：**预处理 → 编译 → 汇编 → 链接** → 可执行目标文件；
- 分工：编译程序（高级语言→汇编/机器代码）、汇编程序（汇编→机器代码）、链接程序（合并目标文件与库）。


**程序和指令的执行过程**
- **指令周期**：取指（PC→MAR→主存→MDR→IR，PC 增量）→ 译码 → 执行（取操作数、运算）→ 访存/写回；
- 程序 = 指令序列，逐条取指执行，**PC 控制执行流**；
- 取指完成后 PC 已指向下一条指令；指令译码由**控制器**完成。

1.冯 诺伊曼计算机结构特点
1.计算机有运算器、控制器、存储器、输入输出五大部分。2.指令和数据都是二进制流，在形式上没有区别。3指令和数据存放在存储器中，按地址访问。4.指令由操作码和地址码组成，操作吗指定操作性质，地址码指定操作数地址。5.采用存储程序方式工作。
CPU = 运算器 + 控制器
