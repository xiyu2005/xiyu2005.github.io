###### 二、超标量
记忆：空间并行，没有细化流水

| 特点 | 说明 |
|---|---|
| **发射宽度** | 一个时钟周期**同时发射多条指令** |
| **硬件** | 多套功能部件、多端口寄存器堆、多译码器 |
| **CPI** | 可小于 1 |
| **实现方式** | 资源重复，提高并行性 |
| **分类** | 静态超标量（编译器调度）、动态超标量（硬件调度） |

##### 三、超流水线（Superpipelining）
时间并行，流水细化。

- 把流水线**功能段进一步细分**；
- 时钟周期变短，时钟频率提高；
- 每个周期仍只发射一条指令，但**流水线级数更多**；
- CPI 可能大于 1（因流水线过深导致冒险增加）。

## 四、超标量 vs 超流水线

| 项目 | 超标量 | 超流水线 |
|---|---|---|
| 并行方式 | 空间并行（多套部件） | 时间并行（细分功能段） |
| 每周期发射 | 多条 | 一条 |
| 时钟频率 | 不变 | 提高 |
| 硬件 | 多套功能部件 | 更多流水线寄存器 |
| 典型 CPI | < 1 | 接近 1 或 > 1 |

## 五、动态调度技术

| 技术 | 作用 |
|---|---|
| **记分牌（Scoreboard）** | 动态调度，顺序发射、乱序执行 |
| **Tomasulo 算法** | 寄存器重命名、乱序执行、保留站 |
| **寄存器重命名** | 消除假数据依赖（WAR、WAW） |
| **乱序执行** | 指令顺序发射，执行顺序可变 |
| **顺序提交** | 保证精确异常 |

# （七）多处理器基本概念
Flynn 分类（按指令流与数据流）

| 类型       | 全称       | 含义           | 典型例子                      |
| -------- | -------- | ------------ | ------------------------- |
| **SISD** | 单指令流单数据流 | 一条指令处理一个数据   | 传统单处理器                    |
| **SIMD** | 单指令流多数据流 | 一条指令同时处理多个数据 | **向量处理器**、GPU、MMX/SSE/AVX |
| **MISD** | 多指令流单数据流 | 多条指令处理同一数据   | 理论模型，几乎不存在                |
| **MIMD** | 多指令流多数据流 | 多条指令处理多个数据   | **多核、多处理器、多计算机**          |


**记忆：**
- Flynn 分类看**指令流和数据流的数量**，不看处理器数量。
- **SIMD = 一条指令，多个数据**；**MIMD = 多条指令，多个数据**。
- 向量处理器属于 **SIMD**。

#### 向量处理器
- **属于 SIMD**，一条向量指令可处理一组数据（向量）。
- 特点：
  - 减少指令数量与取指开销；
  - 适合**规则数据**（数组、矩阵、图像）；
  - 采用**向量流水线**，每个时钟周期产生一个结果；
  - 需要向量寄存器、向量功能部件。
- 与标量处理器对比：标量一次处理一个数据，向量一次处理一批数据。

## 2、硬件多线程的基本概念
硬件多线程(multi-threading)技术是一种**共享单个处理器核内功能部件**的技术。每个
线程相当于一个指令序列，用于**指令执行的功能部件和高速缓存在每个核内仅有一套**。为
了支持多线程并发执行，必须为**每个线程提供单独的通用寄存器组和程序计数器**等用于存
放现场信息的资源，并提供快速的线程切换机制。

**目的：** 隐藏访存延迟，提高 CPU 执行单元利用率。

| 类型             | 切换时机                               | 特点                         |
| -------------- | ---------------------------------- | -------------------------- |
| **细粒度多线程**     | **每个时钟周期**切换线程                     | 交错执行，隐藏短延迟                 |
| **粗粒度多线程**     | 仅在**某个线程出现较大开销阻塞时候**（如 Cache 缺失）切换 | 切换开销较大                     |
| **同时多线程（SMT）** | **同一周期**发射多个线程的指令                  | 共享执行单元，需更多寄存器；典型：Intel 超线程 |

**关键点：**
- 硬件多线程由**硬件**调度，切换无操作系统开销；
- SMT 可在一个周期内发射多个线程的指令；
- 多线程 ≠ 多核：多线程共享一个核的执行资源，多核有独立执行核心。

## 3、多核（Multi-core）处理器的基本概念

- **单芯片**上集成多个处理器核；
- 各核有独立的一级 Cache，共享二级/三级 Cache 和内存；
- 优点：提高并行性、降低功耗、提高能效；
- 核间通信：共享内存、片上网络（NoC）；
- 多核 ≠ 多处理器：多核在同一芯片内，多处理器可在多芯片/多板。

## 4、共享内存多处理器（SMP）的基本概念
采用MIMD方式。
多处理器系统是共享存储多处理器(shared memory multiprocessor,SMP)系统的简
称，它是一种具有共享的单一地址空间的并行处理系统。因此，在多处理器系统中，每个处
理器都可以通过load指令和store指令访问系统中的存储器，不管这些存储器是连接在一
条总线上的共享存储器，还是连接在某个处理器上的本地存储器，这类系统也被称为共享存
储系统。

- **SMP（Symmetric Multiprocessor）**：多个处理器共享同一物理内存和 I/O；
- **对称**：所有处理器地位平等，可访问所有内存，运行同一操作系统；
- 特点：
  - 单一物理地址空间；
  - 通过总线或交叉开关连接；
  - 需要 **Cache 一致性**（如 MESI 协议）；
  - 负载均衡由 OS 调度。
- 与 NUMA 对比：
  - SMP：访问内存时间**一致**；
  - NUMA：访问本地/远程内存时间**不同**。


**一句话记忆：**
> **SISD 单打独斗，SIMD 一条指令管一批数据，MIMD 多核多机；向量处理器属 SIMD；硬件多线程分细粒度、粗粒度、SMT；多核是单芯片多核，SMP 是多处理器共享内存且对称。**
