### 磁盘的物理和格式逻辑化
裸盘 -> 可用盘
1️⃣物理格式化/低级格式化完成磁盘基本物理结构划分，例如 HDD 划分磁道和扇区，并对这些物理单元进行低级错误检测和校正；SSD 则由主控固件通过 FTL 将闪存抽象为逻辑扇区/LBA。  会写入一些低级别信息比如引导扇区信息。
2️⃣分区
磁盘划分为若干逻辑区域（C盘，D盘），每个分区的起始位置和大小记录在主引导记录MBR中。例如C盘：1～100，D盘，100～200.

3️⃣逻辑格式化/高级格式化在物理格式化或底层扇区抽象的基础上创**建文件系统，根目录，设置块大小，簇大小，文件系统类型等参数**
文件系统在格式化时确定盘块/簇的大小，在分区上使用逻辑块，但不负责划分扇区。
磁盘=引导/分区结构（MBR 或 GPT，含分区表） + 多个分区。
单个磁盘分区=引导块+超级块+空闲空间管理+inode+根目录+文件和目录
C盘、D盘是分区，不是逻辑扇区；逻辑扇区是 LBA 层抽象。
4️⃣操作系统安装
选取某个分区作为启动盘，需要在这个分区安装OS。

### 访问时间与响应时间
寻道时间$T_{avg\_seek}$,传动臂将读/写头定位到目标扇区的**磁道**上
平均旋转延迟时间$T_{avg\_rotation}=\frac{1}{2}\frac{1}{RPM}*60$秒（转半圈）
传送时间$T_{avg\_transfer}$:传送数据（磁头扫过一个扇区的时间或者$\frac{一个扇区数据}{数据传输率}$）的时间


$$
T_{access} = T_{avg\_seek}+T_{avg\_rotation}+T_{avg\_transfer}
$$
总响应时间=排队延迟+控制器时间+存取时间($T_{access}$)

### 磁盘的性能指标
1️⃣记录密度：道密度（半径方向 磁道数/长度）位密度（磁道单位长度比特位数），$面密度=道密度 \times 位密度$
#### 2️⃣磁盘容量
格式化容量，非格式化容量
非格式化容量 = 记录面数 * 柱面数 * 每磁道磁化单元数

$$格式化磁盘容量 = 字节数每扇区 \times 平均扇区数 \times 磁道数 \times 表面数 \times 盘片数$$
表面数为2，字节数一般为512B每扇区。磁盘容量$1TB=10^3 GB.$
未格式化容量包括所有可利用单元，**大于格式化后的容量**。

#### 提高磁盘性能：
1️⃣磁盘高速缓存Disk Cache 减少磁盘IO次数 **设备独立性软件层**（缓冲管理)
2️⃣磁盘IO调度算法 优化寻道时间 **设备独立性软件层**（I/O 调度）
3️⃣提前读和延迟写 减少磁盘IO次数 **设备独立性软件层**（缓冲管理策略）
4️⃣优化物理盘块分布 优化平均寻道时间和平均旋转时间 **文件系统层**（磁盘空间分配）

## 总线
###  总线的基本概念 
>[!定义]
内部总线（核内总线）：连接核内寄存器，ALU，指令部件等。
系统总线：CPU，主存，I/O接口互相连接的总线。
系统总线包括：
(1)数据总线：双向，可以设计为和地址线复用。传输指令，操作数，状态字，中断类型号等。
(2)地址总线：单向（只能CPU发到地址线上）。
(3)控制总线 
I/O总线：连接主机和内部的I/O控制器（显卡，网卡）。
通信总线：主机和外部I/O设备的通信。

e.g 1.间址寻址第一次访存得到的信息经(数据总线)传送到CPU。（因为地址总线只能从CPU传出去选择主存地址）

### 总线的组成及性能指标 

#### 1.总线宽度
总线宽度 = 数据总线位数=CPU一次串行传输位数
#### 2.总线工作频率
早期，SDR，工作频率 = 时钟频率；后来一个时钟周期可传输2（DDR）或4（QDR）次数据，工作频率=2或4 * 时钟频率
#### 3.总线带宽
带宽是单位时间内最大容量，与单次实际传输是多少无关。总线宽度W,时钟频率F，一次数据传送所用时间周期数N，则带宽B
$$
B = W \times F/N
$$
>[!例题 2014真题]
> 某同步总线采用数据线和地址线复用方式，期中地址/数据线有32根，总线时钟频率66MHz，每个时钟周期传送两次数据（上升沿和下降沿各传送一次数据），该总线最大数据传输速率（总线带宽）为（ ）。
>A.132MB/s B.264MB/s C.528MB/s D.1056MB/s

解：W=32/8=4B,F=66MHz,N=0.5 B = 528MB/s
#### 总线寻址能力
CPU能访问的最大地址空间。地址线位数决定。16位地址线的最大寻址空间为$2^{16}=65536$个存储单元，如果按字节存储就是65536B。


### 总线事务和定时
##### 总线事务
主设备（CPU，DMAC，仅一个）与从设备（主存，I/O设备，可多个）之间完成一次完整的信息交换过程。包括读/写内存，I/O。
基本阶段：1）地址传输阶段 2）从设备响应阶段 3）数据传送阶段

##### 突发传输与非突发传输
非突发传输方式：每次总线事务传输一个数据单元。
突发传输方式：一次总线事务，主设备进发送数据块首地址，不释放，连续传送多个数据单元，后续地址由硬件实现递增。应用：SDRAM读取，Cache填充。

##### 串行传输与并行传输
串行传输：按比特位依次传输。
并行传输：多条数据线同时传输多个比特位。
##### 总线定时方式
同步通信，异步通信，半同步通信。
同步定时方式：采用统一时钟信号。每个时钟间隔就是总线周期。
异步定时：主从信号握手信号。
1）不互锁：主设备发出请求后，经过预设时延自动撤销。从设备发出回答，自动撤销。 2）半互锁：主设备必须收到回答才能撤回请求。从设备自动撤销回答。3）全互锁：主设备收到回答才能撤销请求，从设备确认请求撤销才可撤销回答。
半同步定时方式：发送按照上升沿，接收方在下降沿识别，增设Wait信号线

分离式定时方式：将一个总线周期分解为两个子周期

## I/O
主机到外设的通路：主机->I/O总线->I/O接口->电缆->外设
![[Pasted image 20260506150302.png]]
端口和接口：I/O端口是I/O接口电路中可被CPU直接访问的寄存器。包括数据端口（R/W），状态端口（R），控制端口（W）。**状态寄存器和控制寄存器可以是同一个**。

#### 独立编址和统一编址
独立编址：I/O端口地址独立于主存的地址空间，不会发生冲突。cpu用专门的I/O指令访问I/O端口。
统一编址（存储器映射方式）：部分主存地址空间分配给I/O端口。cpu主存的访存指令访问I/O端口。地址范围划分。
都是相同的地址线。独立使用部分地址线即可。
### I/O方式
####  程序查询控制
独占查询：cpu一直忙等待外设状态直至操作完成。
定时查询：cpu固定时间周期查询，若就绪，传送一个数据单元。
#### 程序中断方式
能否采用中断I/O：cpu处理中断的时间<外设填满数据缓冲区的时间

中断向量：中断类型号对应的中断服务程序入口地址。
中断向量的存储区域：中断向量表
##### 中断工作流程


（1）中断请求：位不同的中断源设置中断请求标记触发器。
（2）中断响应判优：
中断响应优先级：包括响应优先级（硬件）和处理优先级（软件）。比如中断 A、B、C、D 四个中断信号同时到达中断控制器，那么中断控制器中的中断判优电路会根据特定的规则选择出一个优先级最高的中断信号，比如这里选择中断 C（假设它的响应优先级是最高的），但是这个中断 C 要不要真的被 CPU 响应或处理，就要去看当前中断控制器中的中断屏蔽字了，如果这个屏蔽字对应中断 C 的位是 1 的话，那么说明需要屏蔽掉这个中断，CPU 就不去响应和处理中断 C 了

（3）cpu响应中断条件：
1存在有效中断请求，2CPU处于开中断（除了异常和NMI），**3前指令执行完毕**且无更高优先级任务。
（4）中断响应过程
cpu响应后，由**硬件**完成**中断隐指令**。1关中断2保存断点和程序状态3寻找中断服务程序入口并跳转。
（5）中断处理过程
单重中断，进入中断处理程序后，先关中断；多重中断，进入中断处理程序后，先开中断。

#### DMA方式
DMA（直接存储器存储）用专门的DMA接口控制外设和贮存直接数据交换，不通过cpu。（但是主存仍然可以被cpu访问）。DMA无需保存现场。
DMA部件：主存地址计数器AR，传送长度计数器WC，数据缓冲寄存器BR,DMA请求触发器（在DMAC中），控制/状态逻辑（DMAC），中断机构。

![[Pasted image 20260506174409.png]]
DMA传送过程
1)预处理
DMA 接口开始工作之前，CPU 预置如下信息
DMA 控制逻辑 <- 数据传送方向 写or读主存
DMA 设备地址寄存器<-设备号，并启动设备
DMA 主存地址寄存器 <-交换数据的主存起始地址
字计数器 <- 交换数据的数量

上述工作由 CPU 执行几条输入输出指令完成，这些输入输出指令属于设备驱动程序，也就是说 DMA 传送前由设备驱动程序设置传送参数

当 I/O 设备准备好发送的数据 (输入) 或上次接收的数据已经处理完毕 (输出) 时，它便通过 DMA 接口向 CPU 提出占用总线的申请，若有多个 DMA 同时申请，则按轻重缓急由硬件排队判优逻辑决定优先等。待 I/O 设备得到主存总线的控制权后，数据的传送便由该 DMA 接口进行管理

2)数据传送

DMA 方式是以数据块为单位传送的，以数据输入为例，上图的每个步骤具体操作如下：

① 当设备准备好一个字时，将该字读到 DMA 的数据缓冲寄存器 (BR) 中
② 与此同时设备向 DMA 接口发 DMA 请求
③ DMA 接口向 CPU 申请总线控制权
④ CPU 发回允许信号，表示允许将总线控制权交给 DMA 接口
⑤ 将 DMA 主存地址寄存器中的主存地址送地址总线
⑥ 给主存发送写命令
⑦ 通知设备已被授予一个 DMA 周期，让设备为交换下一个字做准备
⑧ 将 DMA 数据缓冲寄存器的内容通过数据总线送到主存，并写入相应的主存单元
⑨ 修改主存地址和字计数值。
⑩ 中断机构判断数据块是否已传送完毕，若未完毕，继续传送；若已传送完毕，则向 CPU 发出中断信号

3)后处理


DMA和中断区别：
DMA在除1，3阶段，完全不占cpu资源；无需等待指令完成；适合高速外设；dma优先级通常高于cpu；dma由硬件完成传输数据；

DMA传送方法
(1) CPU 停止法。DMA 传输时，由 DMA 控制器发一个停止信号给 CPU，使 CPU 脱离总线，停止访问主存，直到 DMA 传送一块数据结束


(2) 周期挪用法。DMA 传输时，CPU 让出一个总线事务周期，由 DMA 控制器挪用一个存储周期来访问主存，传送完一个数据后立即释放总线。这是一种单数据传送方式


(3) 交替分时访问法。每个存储周期分成两个时间片，一个给 CPU，另一个给 DMA 控制器，这样在每个存储周期内， CPU 和 DMA 控制器都可访问存储器
