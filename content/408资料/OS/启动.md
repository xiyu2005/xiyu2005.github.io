### 一、操作系统安装流程（磁盘准备阶段）

这是将“裸磁盘”变成“可启动系统盘”的过程，对应真题【21-46】第2问。**正确顺序为：**

**物理格式化（低级） → 磁盘分区 → 逻辑格式化（高级） → 安装操作系统**

| 步骤 | 操作名称 | 核心完成内容 |
| :--- | :--- | :--- |
| ① | **物理格式化** | 划分磁道、扇区，为磁盘读写做准备（**磁盘扇区的划分**在此完成） |
| ② | **磁盘分区** | 将磁盘分为多个区，在0号扇区（MBR）建立**分区表**，标记活动分区 |
| ③ | **逻辑格式化** | 在活动分区上建立**文件系统**（创建超级块、inode表、**根目录**、空闲位图等） |
| ④ | **安装操作系统** | 将OS的指令和数据以文件形式复制到活动分区的数据区中 |



### 二、系统引导流程（启动执行阶段）

这是按下电源键到内核加载完毕的过程，对应真题【21-46】第1问和【13-29】。**执行顺序为：**

**ROM中的引导程序（BIOS） → 磁盘引导程序（MBR） → 分区引导程序（Bootloader） → 操作系统初始化程序**

| 阶段 | 存放位置 | 核心职责 |
| :--- | :--- | :--- |
| **1. BIOS (ROM固件)** | 主板ROM芯片 | 硬件自检(POST)、初始化基础硬件、建立简陋中断向量表、读取磁盘0号扇区 |
| **2. 磁盘引导程序** | 硬盘0号扇区（MBR） | 解析分区表，找到标记为**活动**的分区，加载该分区的引导程序 |
| **3. 分区引导程序** | 活动分区第一个扇区 | 即Bootloader，负责加载该分区中操作系统的**内核**到内存（RAM） |
| **4. OS初始化程序** | 内存（RAM）中 | 内核被加载到RAM后，接管硬件，完成后续高级初始化工作 |

> **【13-29】答案：D（RAM）**  
> 解析：BIOS和Bootloader负责把内核从磁盘复制到**主存（RAM）**中，因为CPU只能从RAM（或ROM）取指执行，且RAM执行速度快。ROM中的BIOS是固件，而OS内核最终是在RAM中运行的。

### 三、操作系统内核初始化（接管控制后）

当Bootloader将内核加载到RAM并跳转执行后，OS开始初始化自己，对应真题【22-24】。

**初始化的核心工作包括：**

1. **硬件底层接管**：接管CPU、内存、磁盘、显示器等，替代BIOS的简陋管理。
2. **内存管理初始化**：建立页表、分页机制，划分内核空间/用户空间。
3. **中断/异常重构**：**废弃BIOS建立的简陋中断向量表，重新初始化完整的IDT（中断描述符表）**。
4. **进程管理初始化**：建立PCB链表、调度队列，创建0号和1号内核进程。
5. **文件系统挂载**：加载磁盘上的文件系统（如NTFS/Ext4），挂载根目录。
6. **进入用户态**：创建第一个用户进程（如`init`或`systemd`），启动桌面/终端。

> **【22-24】答案：A（中断向量表）**  
> 解析：  
> - **中断向量表**：虽然BIOS建了一个简陋的，但OS初始化时**重构/重新初始化**了完整的表，属于OS初始化创建。  
> - **根目录**：在**逻辑格式化**（安装阶段）时创建，不属于OS启动初始化。  
> - **硬盘分区表**：在**磁盘分区**（安装阶段）时创建。  
> - **索引结点表(inode)**：在**逻辑格式化**（建立文件系统）时创建。

### 五、核心易混淆点总结（考前必看）

1. **ROM vs RAM**：BIOS在ROM（固件），OS内核在磁盘（安装时）但**运行时在RAM**。
2. **MBR vs 分区引导块**：MBR是磁盘**0号扇区**（全局），存磁盘引导程序和分区表；分区引导块是每个**分区的第一个扇区**（局部），存Bootloader。
3. **物理格式化 vs 逻辑格式化**：物理格式化**划分扇区/磁道**（硬件层面）；逻辑格式化**建立文件系统**（软件层面，如创建根目录、inode）。
4. **中断向量表**：BIOS临时建一个简陋的（为了自检能用），OS启动后**自己重新建一个完整的**，所以考题问“OS初始化创建”时选它。
