> [!tips] 2.2.2：一类内循环包括外循环变量的计算题

>[!question]
>【2022 统考真题】下列程序段的时间复杂度是

```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```

*   A. $O(\log_2 n)$   B. $O(n)$ C. $O(n \log_2 n)$ D. $O(n^2)$

**解析：**
1.  **外层循环**：`i` 的取值为 $1, 2, 4, 8, \dots, 2^k$，其中 $2^k < n$。这是一个指数增长的循环，循环次数为 $\log_2 n$。
2.  **内层循环**：`j` 从 $0$ 增加到 $i$，所以内层循环执行的次数取决于当前的 $i$ 值。
3.  **总执行次数**：将每次外层循环对应的内层循环次数相加。
    $$ \text{Total} = 1 + 2 + 4 + 8 + \dots + 2^k $$
    这是一个等比数列求和。根据等比数列求和公式 $S_n = \frac{a_1(1-q^k)}{1-q}$（这里 $q=2$），总和为：
    $$ S = 2^{k+1} - 1 $$
    由于 $2^k < n$，且 $2^{k+1} \approx 2n$（常数项系数忽略），因此时间复杂度为 $n$。

**正确答案：B. $O(n)$**



>[!question]
>【2025 统考真题】下列程序段的时间复杂度是

```c
int count = 0, i, j;
for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        count++;
```
**选项：**
  A. $O(\log_2 n)$  B. $O(n)$C. $O(n \log_2 n)$ D. $O(n^2)$
**解析：**
1.  **外层循环**：条件是 `i * i <= n`，即 $i \le \sqrt{n}$。所以外层循环 `i` 从 $1$ 增加到 $\sqrt{n}$（向下取整）。
2.  **内层循环**：条件是 `j <= i`，每次执行 $i$ 次。
3.  **总执行次数**：将每次外层循环对应的内层循环次数相加。$$ \text{Total} = 1 + 2 + 3 + \dots + \lfloor\sqrt{n}\rfloor $$
    $$ S \approx \frac{\sqrt{n} \cdot \sqrt{n}}{2} = \frac{n}{2} $$忽略常数系数 $\frac{1}{2}$，时间复杂度为 $O(n)$。

**正确答案：B. $O(n)$**
