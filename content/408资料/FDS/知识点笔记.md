## 第一章数据结构与算法的基本概念
### 数据结构
数据的**最小单位**是**数据项**，数据的**基本单位**是**数据元素**
逻辑结构：线性，树形
物理（存储）结构：顺 序，链式

顺序存储：==随机访问==
结构体存储规则
**规则一：每个成员存储的起始地址 % 该成员的长度 == 0**
**规则二：结构体的长度也必须是最大成员长度的整数倍**
eg:
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
};
struct Student s[6];
```
4+12+2=18B,但实际会填充到20B.
si地址 = s1首地址 + （i-1）* 20;
==缺点：插入或删除，需要移动其他元素==

链式存储
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
    struct Student *next; //后继结点的首地址
};
struct Student s[6];
```

**数据结构三要素：逻辑结构，存储结构，数据的相关操作（运算）**

抽象数据类型ADT:
```
ADT List {
```

## 第六章 图
$G(V,E)$,图中至少有一个V,可以没有E。
$|V|$顶点（vertex）数量，$|E|$边（edge）数量
有向（directed）图，无向（undirected）图，简单图（不存在重复边和指向自身的边，fds仅讨论简单图）。
子图：$G(V,E),G1=(v1,e1)$,其中$v1,e1\in V,E$称G1为G的子图。
完全图（complete）：每两个顶点都有边。
**无向完全图总边数$e = \frac{n(n-1)}{2}$.**
**有向完全图总边数$e = n(n-1)$.**

度（degree）:依附于该顶点v的边数。
**无向图的总度数 = 2 * 边数之和**
**有向图的总入度ID = 总出度OD = 边数之和**
路径：从一个顶点到另一个顶点的顶点序列。出发=结束：环/回路

**连通（connected）**：**无向图中连通=顶点v到w存在路径**，若**无向图**G任意两个顶点连通，则G为**连通图**。否则为非连通图。
**强连通（strongly connected）**：有向图中顶点v到w和w到v都有路径，则v到w是**强连通的**。若**有向图**G中任意两个顶点强连通，则G为强连通图。
有向图中的**极大强连通子图**称为**强连通分量（Strongly connected component）**。

生成树（Spanning tree）：连通图的生成树是一个包含所有顶点的极小连通子图。即：1包括图的所有顶点2只有n-1条边3子图是连通的。
