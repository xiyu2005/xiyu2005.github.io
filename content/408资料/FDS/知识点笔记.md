# 第一章数据结构与算法的基本概念
### 数据结构
数据的**最小单位**是**数据项**，数据的**基本单位**是**数据元素**
逻辑结构：线性，树形
物理（存储）结构：顺 序，链式

顺序存储：==随机访问==
结构体存储规则
**规则一：每个成员存储的起始地址 % 该成员的长度 == 0**
**规则二：结构体的长度也必须是最大成员长度的整数倍**
eg:
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
};
struct Student s[6];
```
4+12+2=18B,但实际会填充到20B.
si地址 = s1首地址 + （i-1）* 20;
==缺点：插入或删除，需要移动其他元素==

链式存储
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
    struct Student *next; //后继结点的首地址
};
struct Student s[6];
```

**数据结构三要素：逻辑结构，存储结构，数据的相关操作（运算）**

## 二维数组
设$a[m][n]$
行优先存储：
```
a[0][0],a[0][1],a[0][2],a[1][0],a[1][1],a[1][2],a[2][0],a[2][1],a[2][2]
```
$ADDR(a[i][j]) = ADDR(a[0][0])+ (n*i+j) * sizeof(int)$
n为总列数(每行元素个数)，sizeof(int)为单个数组元素对应类型的长度。
例如假设a首址为4，$ADDR(a[2][1]) = 4+ (3*2+1) * 4 = 32$
列优先存储:
```
a[0][0],a[1][0],a[2][0],a[3][0];
a[0][1],a[1][1],a[2][1],a[3][1];
```
设m为总行数，即
$ADDR(a[i][j]) = ADDR(a[0][0])+ (m*j+i) * sizeof(int)$
例如a首址4，$a[4][2]$
$$ADDR(a[2][1]) = 4 + (4*1+2) * 4 = 28$$

#### 行优先存储
$a[i][j]$前面的元素个数=在一维数组的下标k,
for $i \ge j,k = 1+2+...+(i-1)+j-1 = \frac{i(i-1)}{2}+j-1$
如果i<j,需要转换一下。
如果是i,j从0开始，令i->+1,j->j+1;$k = \frac{i(i+1)}{2}+j$



**对称矩阵行优先存储（0下标）**
$$
k=
\begin{cases}
\displaystyle \frac{i(i+1)}{2}+j & i\ge j\\[6pt]
\displaystyle \frac{j(j+1)}{2}+i & i<j
\end{cases}
\quad (0\le i,j \le n-1)

$$


**对称矩阵行优先存储（1下标）**
$$
k=
\begin{cases}
\displaystyle \frac{i(i-1)}{2}+j-1 & i\ge j\\[6pt]
\displaystyle \frac{j(j-1)}{2}+i-1 & i<j
\end{cases}
\quad (1\le i,j \le n)

$$
#### 列优先存储
类似推导。给出通式

##### 对称矩阵 列优先压缩存储（0下标）
$$

k = \begin{cases}
i + \dfrac{j(2n - j - 1)}{2}, & i \ge j \\[6pt]
j + \dfrac{i(2n - i - 1)}{2}, & i < j
\end{cases}

$$
##### 对称矩阵 列优先压缩存储（1下标）
$$
k = \begin{cases}
i + \dfrac{(j-1)(2n - j)}{2}, & i \ge j \\[6pt]
j + \dfrac{(i-1)(2n - i)}{2}, & i < j
\end{cases}
$$

```c
// 普通转置：按原矩阵的列序扫描，找到所有列号为 col 的三元组，依次存入转置矩阵 O(cols * num)
void TransposeSMatrix(TSMatrix M, TSMatrix *T) {
    T->rows = M.cols;
    T->cols = M.rows;
    T->num = M.num;
    if (T->num == 0) return;

    int q = 0;  // 指向 T.data 当前存放位置
    for (int col = 1; col <= M.cols; col++) {      // 按原矩阵列号从小到大
        for (int p = 0; p < M.num; p++) {          // 扫描原矩阵所有非零元
            if (M.data[p].j == col) {              // 找到属于第 col 列的元素
                T->data[q].i = M.data[p].j;        // 行变列
                T->data[q].j = M.data[p].i;        // 列变行
                T->data[q].val = M.data[p].val;
                q++;
            }
        }
    }
}
```

```c
// 快速转置：先统计每列非零元个数，计算每列在转置矩阵中的起始位置，一次扫描完成转置
//O(cols+num)
void FastTransposeSMatrix(TSMatrix M, TSMatrix *T) {
    T->rows = M.cols;
    T->cols = M.rows;
    T->num = M.num;
    if (T->num == 0) return;

    int num[M.cols + 1];    // num[col] 表示原矩阵第 col 列的非零元个数（下标 0 不用）
    int cpot[M.cols + 1];   // cpot[col] 表示第 col 列第一个非零元在 T.data 中的存放位置

    // 1. 初始化 num 数组
    for (int col = 1; col <= M.cols; col++)
        num[col] = 0;

    // 2. 统计每列非零元个数
    for (int p = 0; p < M.num; p++)
        num[M.data[p].j]++;

    // 3. 计算每列在转置矩阵中的起始位置
    cpot[1] = 0;   // 第 1 列从 T.data[0] 开始存放
    for (int col = 2; col <= M.cols; col++)
        cpot[col] = cpot[col - 1] + num[col - 1];

    // 4. 扫描原矩阵，根据列号将元素放入转置矩阵的正确位置
    for (int p = 0; p < M.num; p++) {
        int col = M.data[p].j;          // 原矩阵中的列号，即转置后的行号
        int q = cpot[col];              // 该元素在 T.data 中的位置
        T->data[q].i = M.data[p].j;
        T->data[q].j = M.data[p].i;
        T->data[q].val = M.data[p].val;
        cpot[col]++;                    // 该列下一个元素存放位置后移一位
    }
}
```

## 第六章 图
$G(V,E)$,图中至少有一个V,可以没有E。
$|V|$顶点（vertex）数量，$|E|$边（edge）数量
有向（directed）图，无向（undirected）图，简单图（不存在重复边和指向自身的边，fds仅讨论简单图）。
子图：$G(V,E),G1=(v1,e1)$,其中$v1,e1\in V,E$称G1为G的子图。
完全图（complete）：每两个顶点都有边。
**无向完全图总边数$e = \frac{n(n-1)}{2}$.**
**有向完全图总边数$e = n(n-1)$.**

度（degree）:依附于该顶点v的边数。
**无向图的总度数 = 2 * 边数之和**
**有向图的总入度ID = 总出度OD = 边数之和**
路径：从一个顶点到另一个顶点的顶点序列。出发=结束：环/回路

**连通（connected）**：**无向图中连通=顶点v到w存在路径**，若**无向图**G任意两个顶点连通，则G为**连通图**。否则为非连通图。
**强连通（strongly connected）**：有向图中顶点v到w和w到v都有路径，则v到w是**强连通的**。若**有向图**G中任意两个顶点强连通，则G为强连通图。
有向图中的**极大强连通子图**称为**强连通分量（Strongly connected component）**。

生成树（Spanning tree）：连通图的生成树是一个包含所有顶点的极小连通子图。即：1包括图的所有顶点2只有n-1条边3子图是连通的。
