## 第一章数据结构与算法的基本概念
### 数据结构
数据的**最小单位**是**数据项**，数据的**基本单位**是**数据元素**
逻辑结构：线性，树形
物理（存储）结构：顺序，链式

顺序存储：==随机访问==
结构体存储规则
**规则一：每个成员存储的起始地址 % 该成员的长度 == 0**
**规则二：结构体的长度也必须是最大成员长度的整数倍**
eg:
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
};
struct Student s[6];
```
4+12+2=18B,但实际会填充到20B.
si地址 = s1首地址 + （i-1）* 20;
==缺点：插入或删除，需要移动其他元素==

链式存储
```
struct Student{
    int no;             // 学号
    char name[12];      // 姓名
    short age;          // 年龄
    struct Student *next; //后继结点的首地址
};
struct Student s[6];
```

**数据结构三要素：逻辑结构，存储结构，数据的相关操作（运算）**

抽象数据类型ADT:
```
ADT List {
    数据对象: D = {aᵢ | aᵢ ∈ ElemSet, i=1,2,⋯,n, n≥0}
    数据关系: R = { <aᵢ₋₁, aᵢ> | aᵢ₋₁, aᵢ ∈ D, i=2,⋯,n }
    相关操作: 
        InitList(*L)
        ListInsert(*L, i, e)
        ListDelete(*L, i, *e)
        LocateElem(*L, e)
} ADT List
```
