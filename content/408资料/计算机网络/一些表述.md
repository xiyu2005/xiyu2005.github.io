## 一、网络层

| 协议 | 标准表述 |
|---|---|
| **IP** | **无连接、不可靠**的数据报服务（尽力而为交付） |
| **ICMP** | 差错报告 + 询问报文，**封装在 IP 数据报中**（协议号 1） |
| **ARP** | 实现同一局域网内 **IP → MAC** 解析，**广播请求、单播响应** |
| **DHCP** | **UDP**（服务器 67 / 客户端 68），动态主机配置，**即插即用** |

## 二、传输层

| 协议 | 标准表述 |
|---|---|
| **UDP** | **无连接、不可靠、面向报文**，尽最大努力交付；支持一对一/一对多/多对多；首部 8 B；无流量与拥塞控制 |
| **TCP** | **面向连接、可靠、面向字节流**，全双工、一对一；首部最小 20 B；有流量控制和拥塞控制 |

> 最经典对比：**UDP 面向报文，TCP 面向字节流**。

## 三、应用层

| 协议         | 传输层/端口                    | 特点表述                          |
| ---------- | ------------------------- | ----------------------------- |
| **DNS**    | **UDP 53**（TCP 53 用于区域传送） | **分布式、层次化**的域名系统              |
| **FTP**    | **TCP 21（控制）+ 20（数据）**    | 带外控制，控制连接与数据连接分离              |
| **HTTP**   | **TCP 80**                | **无状态、面向事务**；1.0 无连接，1.1 持久连接 |
| **SMTP**   | **TCP 25**                | 邮件**推送（push）**                |
| **POP3**   | **TCP 110**               | 邮件**拉取（pull）**                |


## 四、路由协议

| 协议 | 类别 | 算法 | 传输方式 |
|---|---|---|---|
| **RIP** | IGP | 距离向量 | **UDP 520**，跳数 ≤ 15 |
| **OSPF** | IGP | 链路状态 | **直接用 IP**（协议号 89） |
| **BGP** | **EGP** | 路径向量 | **TCP 179** |

## 五、数据链路层

| 协议 | 标准表述 |
|---|---|
| **CSMA/CD** | 先听后发、边发边听、冲突停发、随机重发 |
| **PPP** | **点对点、面向字节**，**不提供可靠交付**（无序号、无确认） |
| **HDLC** | **面向比特**，可提供可靠交付 |

## 六、"面向 X"易混对照（高频陷阱）

| 表述 | 归属 |
|---|---|
| 面向**报文** | **UDP** |
| 面向**字节流** | **TCP** |
| 面向**连接** | TCP、FTP、SMTP、BGP |
| **无连接** | IP、UDP、ARP、DHCP、HTTP(1.0)、DNS |
| 面向**事务** | HTTP |
| 面向**比特** | HDLC |
| 面向**字节** | PPP |
| **有状态 / 无状态** | TCP 有状态 / HTTP、UDP 无状态（服务器不记） |

## 七、一句话记忆

> **IP 尽力送，UDP 无连接发，TCP 可靠传；DNS 用 UDP、FTP 双连接、HTTP 无状态；RIP 靠 UDP、OSPF 用 IP、BGP 走 TCP；PPP 面向字节不可靠，HDLC 面向比特。**
