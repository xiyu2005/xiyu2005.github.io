# 一、数据的表示和运算

## 1. 现代计算机的结构

* **五大部件**：现代计算机由运算器、输入设备、主存储器、控制器和输出设备组成。其中CPU（中央处理器）包含运算器和控制器，主存储器和CPU共同构成主机，输入输出设备统称为I/O设备或外设。
* **核心功能**：
    * **主存储器**：用于存放数据
    * **运算器**：执行数据的数学运算和逻辑运算

## 2. 数据的表示与运算

### 1）核心问题
* **数据表示**：如何用二进制表示各类数据
* **运算实现**：运算器如何实现算术运算和逻辑运算

### 2）进位计数制
* **常用进制**：
    * **十进制**：人类日常使用的计数系统
    * **二进制**：计算机能够直接识别的计数系统
    * **八进制/十六进制**：程序员常用的辅助表示方法
* **重点考点**：
    * 进制转换：二进制/八进制/十六进制 → 十进制
    * 十进制 → 二进制/八进制/十六进制
    * 二进制、八进制、十六进制之间的相互转换
* **基本概念**：
    * **真值**：实际数值
    * **机器数**：计算机内部的二进制表示形式

## 3. 进位计数制

### 1）最古老的计数方法
* **符号权重原理**：原始部落用竖线（权重1）和横线（权重5）组合计数，如8个苹果=1横线+3竖线，17个苹果=3横线+2竖线
* **罗马数字应用**：
    * **基本符号**：I(1), V(5), X(10), L(50), C(100), D(500), M(1000)
    * **加法原则**：`MDCLXVI` = 1000+500+100+50+10+5+1 = 1666
    * **特殊表示**：IV(4), IX(9)等减法组合
* **局限性**：大数字需要发明新符号（如表示1万需新符号w），不便于扩展

### 2）十进制计数法
#### 阿拉伯数字的起源
* **发明者**：古印度人发明，经阿拉伯人传入欧洲
* **符号系统**：0-9共10个数字符号，每个符号对应不同数值

#### 十进制计数系统的特点
* **位置计数法**：如 975 = 9×10<sup>2</sup> + 7×10<sup>1</sup> + 5×10<sup>0</sup>
* **小数表示**：小数点后第一位权重 10<sup>-1</sup>，第二位 10<sup>-2</sup>，依此类推

#### 位权的概念
* **定义**：数码在不同位置代表不同数值，称为"**位权**"
* **计算规则**：数值 = 数码 × 所在位权，位权 = 基数<sup>n</sup>（n为位置序号）

#### 十进制与人类手指的关系
* **生理基础**：人类10根手指自然形成"逢十进一"的计数习惯
* **计数示例**：篮球记分时，个位记满10分后向十位进1

#### 十进制在加法运算中的应用
* **进位规则**：满10向高位进1，如 8+9=17 记为7（个位）进1（十位）

### 3）r进制计数法
* **基数定义**：每个数位可用符号的个数，如二进制基数为2
* **常见进制**：
    * **二进制**：符号0, 1
    * **八进制**：符号0-7
    * **十六进制**：符号0-9, A(10)-F(15)
* **转换公式**：(N)<sub>r</sub> = ∑(K<sub>i</sub> × r<sup>i</sup>)

#### 例题:二进制转十进制
* **方法1：按位权展开计算**
    `10010010.1101`<sub>(2)</sub> == 146.75<sub>(10)</sub>
* **方法2：记忆位权速查法**
    * **整数位权**：...128, 64, 32, 16, 8, 4, 2, 1
    * **小数位权**：0.5, 0.25, 0.125...
* **运算规则**：
    * **二进制加法**：逢2进1（例：1.1 + 11.1 = 100.0）
    * **八进制加法**：逢8进1（例：5.4 + 1.4 = 7.0）
    * **十六进制加法**：逢16进1（例：5.8 + 0.9 = 6.1）
* **计算机采用二进制的原因**
    * **物理实现**：双稳态器件（高/低电平、正/负电荷）易表示0/1
    * **逻辑对应**：0对应假，1对应真，便于逻辑运算
    * **电路设计**：逻辑门电路天然适合二进制算术运算

### 4）二进制和八进制、十六进制之间的相互转换
#### 二进制转八进制的方法
* **分组原理**: 每3位二进制数对应1位八进制数，因为 2<sup>3</sup>=8，正好覆盖八进制的8种状态。
* **补位规则**:
    * 整数部分不足三位时在高位补零（如二进制数 `1` 补成 `001`）
    * 小数部分不足三位时在低位补零
* **转换示例**:
    * 二进制 `010` → 八进制 `2` (计算：0×2<sup>2</sup> + 1×2<sup>1</sup> + 0×2<sup>0</sup> = 2)
    * 二进制 `111` → 八进制 `7` (计算：1×2<sup>2</sup> + 1×2<sup>1</sup> + 1×2<sup>0</sup> = 7)
    * 二进制 `001` → 八进制 `1`

#### 二进制转十六进制的方法
* **分组原理**: 每4位二进制数对应1位十六进制数，因为 2<sup>4</sup>=16，正好覆盖十六进制的16种状态。
* **补位规则**: 与八进制转换类似，整数部分高位补零，小数部分低位补零。
* **特殊表示**: 二进制 `1100` → 十六进制 `C` (计算：8+4=12，对应字母C）
* **字母对应关系**：A(10)、B(11)、C(12)、D(13)、E(14)、F(15)

#### 八进制转二进制的方法
* **逆向转换**: 每位八进制数展开为3位二进制数
    * 八进制 `2` → 二进制 `010`
    * 八进制 `5` → 二进制 `101`
    * 八进制 `1` → 二进制 `001`
* **小数处理**: 小数点后的每位同样按三位展开（如八进制 `5.5` → 二进制 `101.101`）

#### 十六进制转二进制的方法
* **四位展开**: 每位十六进制数展开为4位二进制数
    * 十六进制 `A`(10) → 二进制 `1010` (计算：8+2=10)
    * 十六进制 `E`(14) → 二进制 `1110` (计算：8+4+2=14)
* **补零规则**: 转换后最高位的零可省略（如 `0001` 可简写为 `1`）

#### 八进制与十六进制的表示方法
* **角标表示法**: (123)<sub>8</sub> 表示八进制数, (A3F)<sub>16</sub> 表示十六进制数
* **字母后缀法**:
    * 二进制：`1010B` (Binary)
    * 十六进制：`1652H` (Hexadecimal)
    * 十进制：`1652D` (Decimal)
* **特殊前缀**: `0x1652` 表示十六进制数（如0x开头的编程表示法）

### 5）各种进制的常见书写方式
* **识别技巧**:
    * 角标法最明确（如 (101)<sub>2</sub>）
    * 字母后缀需记忆对应关系（B/H/D）
    * 编程中 `0x` 前缀专指十六进制
* **易混淆点**:
    * 纯数字串默认可能是十进制
    * 字母结尾时需注意大小写（如 `0FFh` 也是合法表示）
* **术语对照**:
    * hexadecimal (十六进制)
    * decimalism (十进制制)

### 6）十进制和其他进制之间的相互转换
* **十进制转任意进制的方法概述**
    * **分治处理原则**：转换时需要将数值分为整数部分和小数部分分别处理，例如75.3需拆分为75和0.3两个独立部分进行转换
    * **数码位限制**：任何进制中，数码位必须满足 0 ≤ K<sub>i</sub> < r（r为基数），这是进制转换的基本前提条件

#### 整数部分的转换：除基取余法
* **核心原理**：通过连续除以目标基数r，将每次的余数作为对应位的数码值。数学依据是 N = (N div r) × r + (N mod r)
* **操作步骤**：
    1.  用十进制数除以r，记录商和余数
    2.  将商作为新的被除数重复步骤1，直到商为0
    3.  将余数按计算顺序**逆序**排列
* **实例演示**：75转二进制
    > 75÷2=37 余 1 (a<sub>0</sub>)
    > 37÷2=18 余 1 (a<sub>1</sub>)
    > 18÷2=9 余 0 (a<sub>2</sub>)
    > 9÷2=4 余 1 (a<sub>3</sub>)
    > 4÷2=2 余 0 (a<sub>4</sub>)
    > 2÷2=1 余 0 (a<sub>5</sub>)
    > 1÷2=0 余 1 (a<sub>6</sub>)
    > 最终结果为 `1001011`<sub>(2)</sub> (从高位到低位)

#### 小数部分的转换：乘基取整法
* **核心原理**：通过连续乘以目标基数r，将每次乘积的整数部分作为对应位的数码值。
* **操作步骤**：
    1.  用十进制小数乘以r，记录整数部分和小数部分
    2.  将小数部分作为新的被乘数重复步骤1，直到小数部分为0或达到所需精度
    3.  将整数部分按计算顺序**正序**排列
* **实例演示**：0.3转二进制
    > 0.3×2=0.6 → 取整 0 (a<sub>-1</sub>)
    > 0.6×2=1.2 → 取整 1 (a<sub>-2</sub>)
    > 0.2×2=0.4 → 取整 0 (a<sub>-3</sub>)
    > 0.4×2=0.8 → 取整 0 (a<sub>-4</sub>)
    > 0.8×2=1.6 → 取整 1 (a<sub>-5</sub>)
    > 最终结果为 `0.01001...`<sub>(2)</sub> (无限循环)
* **精度问题**：某些十进制小数无法精确表示为有限位二进制小数（如0.3），此时需要根据需求确定转换精度

#### 转换过程中的注意事项与精度问题
* **整数部分**：必须除到商为0为止，余数按**最后到最先**的顺序排列
* **小数部分**：可能出现无限循环情况（如0.3），实际应用中需设定精度截断点
* **混合数处理**：整数和小数部分必须分开转换后再合并结果

### 7）十进制转二进制方法
#### 拼凑法（位权法）
* **适用场景**：当十进制数可以明显拆分为2的幂次方组合时
* **操作步骤**：
    1.  熟记二进制各位的权值（..., 16, 8, 4, 2, 1）
    2.  从高位开始用权值拼凑目标数
    3.  被使用的权值位记1，未使用的记0
* **实例演示**：
    * **260.75转二进制**：
        * 整数部分：256 (2<sup>8</sup>) + 4 (2<sup>2</sup>) → `100000100`
        * 小数部分：0.5 (2<sup>-1</sup>) + 0.25 (2<sup>-2</sup>) → `.11`
        * 合并结果：`100000100.11`
    * **533.125转二进制**：
        * 整数部分：512 (2<sup>9</sup>) + 16 (2<sup>4</sup>) + 4 (2<sup>2</sup>) + 1 (2<sup>0</sup>) → `1000010101`
        * 小数部分：0.125 (2<sup>-3</sup>) → `.001`
        * 合并结果：`1000010101.001`
* **转换技巧**：可先转二进制再转其他进制（如八进制），利用二进制与八进制/十六进制的简便转换关系
    * **例题:十进制转八进制**: `533.125`<sub>(10)</sub> → `1000010101.001`<sub>(2)</sub>
    * 分组: `001|000|010|101.001` → `1025.1`<sub>(8)</sub>

### 8）真值和机器数
* **定义区别**：
    * **真值**：符合人类习惯的实际数值，带有正负号（如+5，-3）
    * **机器数**：计算机存储形式，通过符号位（0/1表示正负）实现正负号的数字化
* **实现原理**：在二进制表示基础上增加最高位作为符号位（0=正，1=负）
* **后续知识**：原码、反码、补码等编码方式将在此基础上展开学习

### 9）知识回顾与重要考点
#### r进制数的定义与转换
* **基本定义**：基数=r，每个数码位可能出现r种字符
* **遵循**："逢r进一"规则
* **位权展开式**：∑(K<sub>i</sub> × r<sup>i</sup>)
* **转换方法**：各数码位与对应位权相乘后求和

#### 二进制与八进制、十六进制的转换
* **转换规则**：
    * **二进制→八进制**：每3位二进制对应1位八进制
    * **二进制→十六进制**：每4位二进制对应1位十六进制
* **补位技巧**：
    * **整数部分**：高位补零（如 `11` → `011`）
    * **小数部分**：低位补零（如 `.11` → `.110`）
* **间接转换**：十六进制→八进制需先转二进制再转八进制

#### 十进制与r进制的转换
* **整数部分处理**：
    * **方法**：除基取余法
    * **注意**：先得到的余数是整数的**低位**
* **小数部分处理**：
    * **方法**：乘基取整法
    * **注意**：先得到的整数是小数的**高位**
* **替代方法**：熟悉位权表后可用拼凑法快速转换（如 2<sup>10</sup> = 1024）

#### 真值与机器数的概念
* **核心区别**：
    * **真值**：人类直观理解的数值（如-5）
    * **机器数**：计算机存储形式（如用1表示负号）
* **符号数字化**：将"+"、"-"转换为0/1存储在最高位

#### 二进制表示小数的精确性问题
* **精确表示条件**：
    * **整数部分**：总能精确表示
    * **小数部分**：当乘基取整法最终得到0时可精确表示（如0.5、0.725）
* **典型反例**：0.3等无法精确表示的小数
* **考试重点**：识别哪些十进制小数可被二进制精确表示

### **一、定点数的表示**

#### **1. 基本概念**
* **定点数 (Fixed-point Number)**：小数点的位置是**固定**的。分为定点整数（小数点在末尾）和定点小数（小数点在符号位后）。
* **无符号数 (Unsigned Number)**：所有二进制位都用来表示数值，没有符号位。
    * **表示范围**：对于n位数，范围是 **`0` 到 `2ⁿ - 1`**。例如，8位无符号整数的范围是 `0` 到 `255`。

#### **2. 有符号数的四种表示码**
(以8位定点整数为例)
##### **1) 原码 (Sign-Magnitude)**
* **规则**：最高位是符号位（0正1负），其余位是数值的绝对值。
* **范围**：`-127` 到 `+127` (即 `-(2⁷-1)` 到 `+2⁷-1`)
* **零的表示**：有两种，`+0` (`00000000`) 和 `-0` (`10000000`)。
* **示例**: `x = -100`
    * `100` 的二进制是 `01100100`
    * `[-100]原` = `11100100`

##### **2) 反码 (One's Complement)**
* **规则**：正数与原码相同；负数是符号位不变，数值位按位取反。
* **范围**：`-127` 到 `+127`
* **零的表示**：有两种，`+0` (`00000000`) 和 `-0` (`11111111`)。
* **示例**: `x = -100`
    * `[-100]原` = `11100100`
    * `[-100]反` = `10011011` (数值位取反)

##### **3) 补码 (Two's Complement)**
* **规则**：正数与原码相同；负数是其反码在末位加1。
* **范围**：**`-128` 到 `+127`** (即 `-2⁷` 到 `+2⁷-1`)
* **零的表示**：**唯一**，`00000000`。
* **示例**: `x = -100`
    * `[-100]反` = `10011011`
    * `[-100]补` = `10011100` (反码+1)
* **快速求补技巧**: 已知 `[x]补`，求 `[-x]补` 的方法是：**连同符号位在内，所有位按位取反，末位加1**。
    * 例：`[+13]补` = `00001101`
    * 取反: `11110010`
    * 加1: `11110011`，即为 `[-13]补`。

##### **4) 移码 (Excess/Biased Code)**
* **规则**：**仅用于整数**。基于补码，将**符号位取反**即可。
* **范围**：`-128` 到 `+127`
* **零的表示**：唯一。
* **特点**：
    * 便于比较大小：可以直接按无符号数规则比较大小。
    * 常用于浮点数的**阶码**表示。
* **示例**: `x = -100`
    * `[-100]补` = `10011100`
    * `[-100]移` = `0011100` (补码符号位取反)

#### **3. 示例：二进制序列求真值**
给定一个8位二进制序列 `10011011`，其真值是多少？

* **如果为原码**: `1` (负) + `0011011` (27) → **-27**
* **如果为反码**: 需转为原码 `11100100` → `1` (负) + `1100100` (100) → **-100**
* **如果为补码**: 需转为原码 (数值位取反+1) `11100101` → `1` (负) + `1100101` (101) → **-101**

### **一、各种码的作用**

#### **1. 加减运算**

* **原码的运算缺陷**：
    * 原码无法将符号位和数值位统一处理。如果直接按位相加，会出现错误。
    * **示例**: `(+14) + (-14)`
        > `[+14]原` = `00001110`
        > `[-14]原` = `10001110`
        > 直接相加: `10011100` → 换算为真值是 **-28**，结果错误。
    * **硬件实现问题**：若要正确运算，硬件（ALU）必须能判断符号，并配备独立的加法器和减法器，这会使电路设计变得非常复杂且昂贵。

* **核心思想：用加法代替减法**
    * **模运算原理**：在一个固定的计数范围内（即“模”），减法可以等效为加一个“补数”。
        > **生活中的例子 (时钟)**：在一个以12为模的系统中，`10 - 3` 和 `10 + 9` 的结果都指向7点，因此 `(-3)` 和 `(+9)` 在模12的意义下是等价的。这里的 `9` 就是 `-3` 的补数。
    * **补码的数学本质**：负数的补码，其本质就是“模”减去该数的绝对值。
        > **示例**: 在8位系统中，模为 `2⁸ = 256`。求 `-14` 的补码：
        > `[-14]补` = 256 - 14 = 242
        > `242` 的二进制即为 `11110010`。这与我们用“**取反加一**”的快捷方式算出的结果 `(10001110 → 11110001 + 1 → 11110010)` 是完全一致的。
    * **电路简化**：使用补码后，计算机的ALU**只需要一个加法器**就可以完成所有的加法和减法运算，因为 `A - B` 等价于 `A + [-B]补`。硬件设计得到极大简化。
        > `(+14) + (-14)`
        > `[+14]补` = `00001110`
        > `[-14]补` = `11110010`
        > 相加: `1 00000000` → 丢弃溢出的进位后，结果为 `0`，正确。

#### **2. 移码 (Excess/Biased Code)**

* **核心作用**：**便于硬件直接比较数值大小**。
* **编码特点**：移码的二进制表示（当被看作无符号数时）与其真值的大小是**单调递增**的。这意味着，硬件可以复用简单的无符号数比较电路，直接按位比较移码的大小，就能得到其真值的大小关系。
* **应用场景**：这个特性使移码特别适用于**浮点数的阶码（Exponent）部分**的比较。
