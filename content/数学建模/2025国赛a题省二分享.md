浙大在2025国赛a题中，33支队伍参赛，1支队伍拿到了省一推国奖，1支省二，5支省三。
我们队伍获得了省二，同时我也是校赛的一等奖。可能算不上特别厉害，但是看到校内没有什么参赛经验帖分享，还是想写一点东西。
### 备赛期间：

- **全真模拟**：在暑假，我个人独自进行了**2次**往年真题的建模、编程、写作全流程模拟。进行了7次的建模+编程做题和部分写作模拟。
    
- **研读论文**：我阅读了官网上近5年的国赛a题论文，学习论文的**行文结构、摘要写法、图表规范和模型亮点**的呈现方式。最重要的是摘要的写作。
    
- **提前准备模版**：我是写作手，因此我提前准备了一些论文和流程图的模版，有些是咸鱼一块钱买来的，有些是我自己画的。我放在下面介绍。
- **模拟赛**：只有一次校赛和暑假八校联合的集训赛。


浙大会提供上海交大组织的线上培训讲座，一些内容还是比较实用的。以及会组织一次“火花杯”模拟赛，但是赛题质量堪忧。

我觉得浙大自己缺少一次整体的在暑假的培训赛，只有一次校赛还是太少了。而且校赛的时间我记得有快一周吧，并不是符合国赛三天三夜的。如果能有一次的话可能会更好一点。

### 比赛期间

一个明确的时间表是成功的关键，以下是我们在比赛前做的，建议大家参考并制定自己的时间表：

| 日期      | 时间            | 任务内容                                                       |
| ------- | ------------- | ---------------------------------------------------------- |
| **9.4** | 18:00 - 22:30 | 选题，规划大致思路，建立初步模型。借助AI完成问题背景、问题提出、问题分析（初步）和模型假设（初步）。        |
| **9.5** | 8:30 - 11:45  | **第一问**：进行充分讨论，建立模型，完成模型框架的代码；撰写第一问的论文问题分析与部分模型建立内容。       |
| **9.5** | 午休            | 休息                                                         |
| **9.5** | 14:00 - 17:30 | **第一问**：完善并审查模型，进行求解，编写代码并运行，将结果展现在论文中。                    |
| **9.5** | 18:00 - 22:30 | **第二问**：大概率为优化模型，按照优化模型范式建立。编写初步代码，撰写第二问的问题分析与模型建立部分。      |
| **9.6** | 8:30 - 11:45  | **第二问**：优化模型求解，编写程序运行求解，在论文中展现结果。                          |
| **9.6** | 14:00 - 17:30 | **第三/四问**：可能是优化模型的约束改变或独立新问题。建立对应模型，撰写相关论文部分。              |
| **9.6** | 18:00 - 22:30 | **第三/四问**：求解模型，在论文中呈现结果。                                   |
| **9.7** | 8:30 - 11:30  | **论文收尾**：审查、修正、改进所有模型；完成模型检验、灵敏度分析等；完成参考文献、附录；添加流程图和可视化图表。 |
| **9.7** | 13:30 - 17:00 | **最终审查**：全面审查模型，对论文进行最后的润色。                                |
| **9.7** | **18:00**     | **第一次提交MD5**，将当前版本作为存档。                                    |
| **9.7** | **19:30**     | **提交最终版本MD5**。                                             |
| **9.7** | **20:30**     | **提交所有材料**。                                                |
这个时间表确实很理想，所以我们后期的进度几乎滞后了半天多，好在最后及时在19:45提交了md5码。
