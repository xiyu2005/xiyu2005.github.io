

#### **1. 场景元素与变量定义**

|     符号 (Symbol)     | 中文释义 (Description)              | 定义域 / 数值 (Domain / Value)  |
| :-----------------: | :------------------------------ | :------------------------- |
|         `i`         | **导弹**的索引                       | `i ∈ {1, 2, 3}`            |
|         `j`         | **无人机**的索引                      | `j ∈ {1, 2, 3, 4, 5}`      |
|     $\vec{P}_C$     | **真实目标**的**圆心**位置向量（投影）         | `(0, 200)`                 |
|        $R_T$        | **真实目标**的半径（投影）                 | `7` 米                      |
| $\vec{P}_{FY_j}(t)$ | 第 `j` 架**无人机**在时间 `t` 的位置向量（投影） | -                          |
| $\vec{P}_{M_i}(t)$  | 第 `i` 枚**导弹**在时间 `t` 的位置向量（投影）  | -                          |
|     $R_{cloud}$     | **烟幕球**的半径（投影为圆）                | `10` 米                     |
|      $W_i(t)$       | 由导弹 `i` 和真实目标形成的**威胁区域**（类三角形）  | -                          |
|     $\alpha_j$      | 无人机 `j` 的航向角                    | `α_j ∈ [0, 2π)`            |
|     $v_{FY_j}$      | 无人机 `j` 的飞行速度                   | `v_{FY_j} ∈ [70, 140]` m/s |

---

#### **2. 运动学模型 (Kinematic Models)**

* **导弹运动模型**: 导弹 `i` 的位置由其初始位置和速度向量决定。
  $$\vec{P}_{M_i}(t) = \vec{P}_{M_i}(0) + \vec{v}_{M_i} \cdot t$$

* **无人机运动模型**: 无人机 `j` 的位置由其初始位置、选择的航向角 $\alpha_j$ 和速度 $v_{FY_j}$ 决定。
  $$\vec{P}_{FY_j}(t) = \vec{P}_{FY_j}(0) + \vec{v}_{FY_j}(\alpha_j, v_{FY_j}) \cdot t$$

---

#### **3. 综合判定准则**

一次成功的防御行动，是在某一时刻 `t`，无人机 `j` 部署的烟幕，相对于导弹 `i`，**必须同时满足以下两个条件**。

##### **3.1 部分遮蔽准则 (Partial Obscuration Criterion)**

* **准则描述**: 无人机 `j` 形成的半径为 $R_{cloud}$ 的烟幕圆，其**至少有部分**进入了由导弹 `i` 和真实目标圆（半径$R_T$）所构成的“V”形威胁区域 $W_i(t)$。
* **数学依据**: 该几何条件等价于：烟幕圆的圆心（即无人机位置 $\vec{P}_{FY_j}(t)$）到威胁区域 $W_i(t)$ 的最短距离，必须小于或等于烟幕圆的半径 $R_{cloud}$。
* **数学表达式**:
    设：
    * 威胁区域的半角: $\gamma_T(t) = \arcsin\left(\frac{R_T}{\|\vec{P}_C - \vec{P}_{M_i}(t)\|}\right)$
    * 无人机方向与区域中轴线的夹角: $\delta(t) = \arccos\left(\frac{(\vec{P}_C - \vec{P}_{M_i}(t)) \cdot (\vec{P}_{FY_j}(t) - \vec{P}_{M_i}(t))}{\|\vec{P}_C - \vec{P}_{M_i}(t)\| \cdot \|\vec{P}_{FY_j}(t) - \vec{P}_{M_i}(t)\|}\right)$

    则**部分遮蔽准则**成立的条件是：
    $$\|\vec{P}_{FY_j}(t) - \vec{P}_{M_i}(t)\| \cdot \sin\left(\max(0, \delta(t) - \gamma_T(t))\right) \le R_{cloud}$$

##### **3.2 相对距离优势准则 (Relative Distance Advantage Criterion)**

* **准则描述**: 在同一时刻 `t`，烟幕圆**最靠近**真实目标圆心的边缘点，必须**严格地**比导弹更靠近真实目标圆心。
* **数学依据**: 烟幕圆边缘与目标圆心的最短距离为 $\|\vec{P}_{FY_j}(t) - \vec{P}_C\| - R_{cloud}$。此距离必须小于导弹与目标圆心的距离 $\|\vec{P}_{M_i}(t) - \vec{P}_C\|$。
* **数学表达式**:
    $$\|\vec{P}_{FY_j}(t) - \vec{P}_C\| - R_{cloud} < \|\vec{P}_{M_i}(t) - \vec{P}_C\|$$
    整理得：
    $$\|\vec{P}_{FY_j}(t) - \vec{P}_C\| < \|\vec{P}_{M_i}(t) - \vec{P}_C\| + R_{cloud}$$

---
#### **4. 完整有效性命题**

综合以上所有逻辑，我们可以给出判定一架无人机 `j` 的某个航向角 $\alpha_j$ 是否**有效**的最终数学命题。当且仅当以下表达式为**真**时，航向角 $\alpha_j$ 被认为是有效的：

$$\exists v_{FY_j} \in [70, 140] \quad \exists t > 0 \quad \exists i \in \{1, 2, 3\} \quad \text{s.t.}$$

$$\left( \|\vec{P}_{FY_j}(t) - \vec{P}_{M_i}(t)\| \cdot \sin\left(\max(0, \delta(t) - \gamma_T(t))\right) \le R_{cloud} \right)$$$$\land$$$$\left( \|\vec{P}_{FY_j}(t) - \vec{P}_C\| < \|\vec{P}_{M_i}(t) - \vec{P}_C\| + R_{cloud} \right)$$

* **其中**:
    * `∃` (存在)：表示至少存在一个满足条件的元素。
    * `s.t.` (使得)：引出必须满足的条件。
    * `∧` (逻辑与)：表示上下两个括号内的准则必须**同时成立**。
