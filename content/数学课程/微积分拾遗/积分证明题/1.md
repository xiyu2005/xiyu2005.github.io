设 $f \in C^2[0, 1]$，且 $f(0) = f(1) = 1$，证明：

$$|f(x) - 1| \le \frac{1}{4} \int_0^1 |f''(x)| dx, \quad \forall x \in [0, 1]$$

证明如下：

令 $u(x) = f(x) - 1$，则 $u(0) = u(1) = 0$。根据泰勒公式的积分余项：
$u(x) = u(0) + u'(0)x + \int_0^x (x-t)u''(t)dt = u'(0)x + \int_0^x (x-t)u''(t)dt$
$u(x) = u(1) + u'(1)(x-1) + \int_1^x (x-t)u''(t)dt = u'(1)(x-1) - \int_x^1 (x-t)u''(t)dt$

由 $u(1)=0$ 可知 $u'(0) = -\int_0^1 (1-t)u''(t)dt$。代入第一式得：
$u(x) = -x\int_0^1 (1-t)u''(t)dt + \int_0^x (x-t)u''(t)dt$
$u(x) = -x\int_0^x (1-t)u''(t)dt - x\int_x^1 (1-t)u''(t)dt + \int_0^x (x-t)u''(t)dt$
化简得：
$u(x) = \int_0^x (x-t-x+xt)u''(t)dt - \int_x^1 x(1-t)u''(t)dt$
$u(x) = \int_0^x t(x-1)u''(t)dt - \int_x^1 x(1-t)u''(t)dt$

取绝对值：
$|u(x)| \le \int_0^x t(1-x)|u''(t)|dt + \int_x^1 x(1-t)|u''(t)|dt$
因为 $t \le x$ 且 $1-t \le 1-x$ 在对应区间内成立，故：
$|u(x)| \le x(1-x) \left( \int_0^x |u''(t)|dt + \int_x^1 |u''(t)|dt \right) = x(1-x) \int_0^1 |u''(t)|dt$

由于 $x(1-x)$ 在 $[0, 1]$ 上的最大值为 $\frac{1}{4}$，得证：
$|f(x)-1| \le \frac{1}{4} \int_0^1 |f''(t)|dt$
