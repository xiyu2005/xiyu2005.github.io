T8

已知 $X, Y$ 相互独立且均服从 $N(0,1)$，令 $Z_1 = \max\{X,Y\}$，$Z_2 = \min\{X,Y\}$。判断关于 $Z_1+Z_2$、$Z_1-Z_2$ 的期望，以及 $Z_1$ 与 $Z_2$ 的相关性和独立性选项的正误。

破解此类极值问题的核心利器是恒等式转化：不管 $X, Y$ 服从什么分布，永远有：
$$Z_1 + Z_2 = X + Y$$
$$Z_1 - Z_2 = |X - Y|$$

利用这两个式子，可以将复杂的极值问题转化为简单的和差问题。由第一个式子可直接得出：
$$E(Z_1) + E(Z_2) = E(X) + E(Y) = 0$$
 关于 $E(Z_1)$ 和 $E(Z_2)$ 的具体求法
最简便的方法是“联立方程组法”。前文已知 $Z_1 - Z_2 = |X - Y|$，且 $X-Y \sim N(0,2)$。利用正态分布绝对值的期望公式 $E(|W|) = \sigma \sqrt{2/\pi}$，代入 $\sigma = \sqrt{2}$，可得：
$$E(Z_1 - Z_2) = \frac{2}{\sqrt{\pi}}$$

联立方程组：
$$
\begin{cases}
E(Z_1) + E(Z_2) = 0 \\
E(Z_1) - E(Z_2) = \frac{2}{\sqrt{\pi}}
\end{cases}
$$
即可直接解出：
$$E(Z_1) = \frac{1}{\sqrt{\pi}}$$
$$E(Z_2) = -\frac{1}{\sqrt{\pi}}$$

如果使用通法（分布函数法），则是先求 $Z_1$ 的分布函数 $F(z) = [\Phi(z)]^2$，求导得到密度函数 $f(z) = 2\Phi(z)\phi(z)$，然后利用期望定义做分部积分，同样可以算出 $\frac{1}{\sqrt{\pi}}$，但计算量较大，考场上优先选联立法。

判断相关性时，计算协方差：
$$Cov(Z_1, Z_2) = E(Z_1 Z_2) - E(Z_1)E(Z_2)$$
由于 $Z_1 Z_2 = XY$ 且 $X,Y$ 独立，所以 $E(XY)=0$，得出协方差为 $\frac{1}{\pi} > 0$，说明它们是正相关的，而不是“不相关”。

判断独立性时，因为恒有 $Z_1 \ge Z_2$，即 $P(Z_1 < Z_2) = 0$，不满足独立事件乘积的条件，所以它们一定不独立。


t9 F分布与t分布
t分布与F分布是统计学与考研数学中三大抽样分布的核心成员。它们共同的基础是**标准正态分布**与**卡方分布**（\(\chi^2\)分布）。若 \(X \sim N(0,1)\)，\(Y \sim \chi^2(n)\)，且 \(X\) 与 \(Y\) 相互独立，就构成了这两个分布的基础构件。

**t分布**
若 \(X \sim N(0,1)\)，\(Y \sim \chi^2(n)\)，且 \(X, Y\) 独立，则构造统计量：
$$T = \frac{X}{\sqrt{Y/n}} \sim t(n)$$
它的概率密度函数关于 \(y\) 轴对称，形状类似标准正态分布，但**峰更矮、尾部更厚**。
*   **期望与方差**：当 \(n > 1\) 时，\(E(T) = 0\)；当 \(n > 2\) 时，\(Var(T) = \frac{n}{n-2}\)（注意方差始终大于1，大于标准正态分布的方差）。
*   **极限性质**：当自由度 \(n \to \infty\) 时，t分布依分布收敛于标准正态分布 \(N(0,1)\)。
*   **重要分位数性质**：由于其对称性，满足 \(t_{1-\alpha}(n) = -t_{\alpha}(n)\)。

**F分布

若 $X \sim \chi^2(n_1)，Y \sim \chi^2(n_2)$，且 $X, Y$ 独立，则构造统计量：
$$F = \frac{X/n_1}{Y/n_2} \sim F(n_1, n_2)$$

1. **平方关系（t分布与F分布的桥梁）**：若 $T \sim t(n)$，则 $T^2 \sim F(1, n)$。这是因为 $T^2 = \frac{X^2/1}{Y/n}$，而 $X^2 \sim \chi^2(1)$。这个结论常用来推导或证明某些统计量的分布。
2. **倒数关系（F分布自身性质）**：若 $F \sim F(n_1, n_2)$，则 $\frac{1}{F} \sim F(n_2, n_1)$。
3. **分位数转换（查表必备）**：由于F分布表通常只给出上侧分位数（即右侧概率较小的情况），对于左侧分位数需要利用倒数关系转换：
$$F_{1-\alpha}(n_1, n_2) = \frac{1}{F_{\alpha}(n_2, n_1)}$$
t分布同样存在对称转换，用于查表$t_{1-\alpha}(n) = -t_{\alpha}(n)$
