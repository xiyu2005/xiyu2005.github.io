## 第4章 随机变量的数字特征

### 4.1 数学期望

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 离散型期望 | $P(X=x_i)=p_i$ | $E(X)=\sum_i x_ip_i$ | 加权平均 |
| 连续型期望 | 密度 $f(x)$ | $E(X)=\int_{-\infty}^{+\infty}xf(x)\,dx$ | 积分平均 |
| 离散型函数期望 | $Y=g(X)$ | $E[g(X)]=\sum_i g(x_i)p_i$ | 不必先求 $Y$ 的分布 |
| 连续型函数期望 | $Y=g(X)$ | $E[g(X)]=\int_{-\infty}^{+\infty}g(x)f(x)\,dx$ | 直接对 $X$ 积分 |
| 二维函数期望 | 联合密度 $f(x,y)$ | $E[g(X,Y)]=\iint g(x,y)f(x,y)\,dxdy$ | 二维随机变量函数 |
| 线性性 | 不要求独立 | $E(aX+bY+c)=aE(X)+bE(Y)+c$ | 最常用性质 |
| 多项线性性 | 不要求独立 | $E(c_0+\sum_{i=1}^n c_iX_i)=c_0+\sum_{i=1}^n c_iE(X_i)$ | 线性组合 |
| 乘积期望 | $X,Y$ 独立 | $E(XY)=E(X)E(Y)$ | 必须注意独立条件 |

### 4.2 方差

| 类型      | 条件/对象     | 公式                                     | 说明        |
| ------- | --------- | -------------------------------------- | --------- |
| 方差定义    | 任意随机变量    | $D(X)=Var(X)=E\{[X-E(X)]^2\}$          | 衡量波动      |
| 方差计算公式  | 常用        | $D(X)=E(X^2)-[E(X)]^2$                 | 考试高频      |
| 标准差     | 方差存在      | $\sigma(X)=\sqrt{D(X)}$                | 与原变量同量纲   |
| 常数方差    | $C$ 为常数   | $D(C)=0$                               | 常数不波动     |
| 线性变换方差  | $a,b$ 为常数 | $D(aX+b)=a^2D(X)$                      | 平移不影响方差   |
| 两变量线性组合 | 一般情况      | $D(aX+bY)=a^2D(X)+b^2D(Y)+2abCov(X,Y)$ | 不独立时要有协方差 |
| 独立时线性组合 | $X,Y$ 独立  | $D(aX+bY)=a^2D(X)+b^2D(Y)$             | 协方差项为 0   |
| 独立和的方差  | $X,Y$ 独立  | $D(X+Y)=D(X)+D(Y)$                     | 方差可加      |

### 4.3 协方差与相关系数

| 类型      | 条件/对象         | 公式                                            | 说明       |
| ------- | ------------- | --------------------------------------------- | -------- |
| 协方差定义   | $X,Y$         | $Cov(X,Y)=E\{[X-E(X)][Y-E(Y)]\}$              | 共同变化趋势   |
| 协方差计算公式 | 常用            | $Cov(X,Y)=E(XY)-E(X)E(Y)$                     | 最常用于做题   |
| 对称性     | $X,Y$         | $Cov(X,Y)=Cov(Y,X)$                           | 顺序可换     |
| 方差关系    | 同一变量          | $Cov(X,X)=D(X)$                               | 协方差推广了方差 |
| 数乘      | $a,b$ 为常数     | $Cov(aX,bY)=abCov(X,Y)$                       | 系数直接提出   |
| 加法      | $X_1,X_2,Y$   | $Cov(X_1+X_2,Y)=Cov(X_1,Y)+Cov(X_2,Y)$        | 可拆开      |
| 独立推出不相关 | $X,Y$ 独立      | $Cov(X,Y)=0$                                  | 反过来一般不成立 |
| 相关系数    | $D(X),D(Y)>0$ | $\rho_{XY}=\dfrac{Cov(X,Y)}{\sqrt{D(X)D(Y)}}$ | 标准化协方差   |
| 相关系数范围  | $X,Y$         | $-1\le\rho_{XY}\le1$                          | 衡量线性相关强度 |

### 4.4 常见分布的期望与方差

| 分布 | 记号 | 分布律/密度核心 | 期望 | 方差 | 常用提醒 |
|---|---|---|---|---|---|
| 0-1 分布 | $X\sim 0\text{-}1(p)$ | $P(X=1)=p$ | $p$ | $p(1-p)$ | $E(X)=P(X=1)$ |
| 二项分布 | $X\sim B(n,p)$ | $P(X=k)=C_n^kp^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ | 独立重复试验次数 |
| 泊松分布 | $X\sim \pi(\lambda)$ | $P(X=k)=e^{-\lambda}\dfrac{\lambda^k}{k!}$ | $\lambda$ | $\lambda$ | 常记 $P(0),P(1),P(2)$ |
| 均匀分布 | $X\sim U(a,b)$ | $f(x)=\dfrac1{b-a}$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^2}{12}$ | 二维均匀常用面积比 |
| 正态分布 | $X\sim N(\mu,\sigma^2)$ | 钟形密度 | $\mu$ | $\sigma^2$ | 做概率先标准化 |
| 指数分布 | $X\sim E(\lambda)$ | $f(x)=\lambda e^{-\lambda x},x>0$ | $\dfrac1\lambda$ | $\dfrac1{\lambda^2}$ | 有无记忆性 |

### 4.5 正态分布与指数分布常用公式

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 标准正态化 | $X\sim N(\mu,\sigma^2)$ | $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$ | 正态概率必备 |
| 正态区间概率 | $X\sim N(\mu,\sigma^2)$ | $P(a<X<b)=\Phi(\dfrac{b-\mu}{\sigma})-\Phi(\dfrac{a-\mu}{\sigma})$ | 查表 |
| 标准正态对称性 | $Z\sim N(0,1)$ | $\Phi(-x)=1-\Phi(x)$ | 化负为正 |
| 二元正态边缘 | $(X,Y)\sim N(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho)$ | $X\sim N(\mu_1,\sigma_1^2),Y\sim N(\mu_2,\sigma_2^2)$ | 参数顺序要看清 |
| 二元正态协方差 | 同上 | $Cov(X,Y)=\rho\sigma_1\sigma_2$ | $\rho$ 是相关系数 |
| 二元正态独立判定 | 联合正态 | $X,Y$ 独立 $\Longleftrightarrow Cov(X,Y)=0$ | 正态下特有 |
| 指数分布函数 | $X\sim E(\lambda)$ | $F(x)=P(X\le x)=1-e^{-\lambda x}$ | $x>0$ |
| 指数尾概率 | $X\sim E(\lambda)$ | $P(X>x)=e^{-\lambda x}$ | 常用于等待时间 |
| 无记忆性 | $X\sim E(\lambda)$ | $P(X>a+b\mid X>a)=P(X>b)$ | 条件概率秒解 |

## 第5章 大数定律与中心极限定理

### 5.1 依概率收敛与大数定律

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 依概率收敛定义 | $X_n\to a$ | $\forall\varepsilon>0,\lim_{n\to\infty}P(|X_n-a|\ge\varepsilon)=0$ | 偏离概率趋于 0 |
| 辛钦大数定律 | $X_i$ 独立同分布，$E(X_i)=\mu$ | $\dfrac1n\sum_{i=1}^nX_i\xrightarrow{P}\mu$ | 样本平均趋于总体均值 |
| 函数形式大数定律 | $h(X_i)$ 独立同分布 | $\dfrac1n\sum_{i=1}^nh(X_i)\xrightarrow{P}E[h(X)]$ | 常考 $\sum h(X_i)/n$ |
| 样本均值记号 | $\overline X=\dfrac1n\sum X_i$ | $\overline X\xrightarrow{P}E(X)$ | 大数定律核心 |
| 连续函数推论 | $\overline X\xrightarrow{P}\mu$ | $g(\overline X)\xrightarrow{P}g(\mu)$ | 例如线性函数 |
| 贝努里大数定律 | $X\sim B(n,p)$，频率 $X/n$ | $\dfrac Xn\xrightarrow{P}p$ | 频率稳定于概率 |

### 5.2 切比雪夫不等式

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 切比雪夫不等式 | $E(X)=\mu,D(X)=\sigma^2$ | $P(|X-\mu|\ge\varepsilon)\le\dfrac{\sigma^2}{\varepsilon^2}$ | 估计偏离概率上界 |
| 均值附近概率 | 同上 | $P(|X-\mu|<\varepsilon)\ge1-\dfrac{\sigma^2}{\varepsilon^2}$ | 给保守下界 |
| 频率方差 | $X\sim B(n,p)$ | $D(\dfrac Xn)=\dfrac{p(1-p)}n$ | 频率题常用 |
| 频率切比雪夫 | $X\sim B(n,p)$ | $P(|\dfrac Xn-p|<\varepsilon)\ge1-\dfrac{p(1-p)}{n\varepsilon^2}$ | 求至少多大概率 |

### 5.3 中心极限定理

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 独立同分布求和 | $E(X_i)=\mu,D(X_i)=\sigma^2$ | $\sum_{i=1}^nX_i\approx N(n\mu,n\sigma^2)$ | $n$ 大时 |
| 求和标准化 | 同上 | $\dfrac{\sum_{i=1}^nX_i-n\mu}{\sigma\sqrt n}\approx N(0,1)$ | 查正态表 |
| 样本均值近似 | 同上 | $\overline X\approx N(\mu,\dfrac{\sigma^2}{n})$ | 均值更稳定 |
| 样本均值标准化 | 同上 | $\dfrac{\overline X-\mu}{\sigma/\sqrt n}\approx N(0,1)$ | 常考概率 |
| 二项正态近似 | $X\sim B(n,p)$ | $X\approx N(np,np(1-p))$ | 棣莫弗-拉普拉斯定理 |
| 二项标准化 | $X\sim B(n,p)$ | $\dfrac{X-np}{\sqrt{np(1-p)}}\approx N(0,1)$ | 大 $n$ 二项题 |
| 频率正态近似 | $X\sim B(n,p)$ | $\dfrac{X/n-p}{\sqrt{p(1-p)/n}}\approx N(0,1)$ | 频率区间概率 |

### 5.4 第5章常见题型对应公式

| 题型信号                   | 应用公式                                     | 解题提醒                      |
| ---------------------- | ---------------------------------------- | ------------------------- |
| 出现“依概率收敛”              | 大数定律                                     | 先看平均的是 $X_i$ 还是 $h(X_i)$  |
| 出现 $\frac1n\sum X_i^2$ | $\frac1n\sum X_i^2\xrightarrow{P}E(X^2)$ | 用 $E(X^2)=D(X)+[E(X)]^2$  |
| 出现“大样本平均值概率”           | $\overline X\approx N(\mu,\sigma^2/n)$   | 先求单个 $X$ 的 $\mu,\sigma^2$ |
| 出现“次数”且 $n$ 很大         | $B(n,p)\approx N(np,np(1-p))$            | 先求单次事件概率 $p$              |
| 出现“至少概率不小于”            | 切比雪夫或中心极限定理                              | 切比雪夫保守，中心极限定理近似           |

## 第6章 统计量与抽样分布

### 6.1 样本与常见统计量

| 类型 | 公式 | 说明 |
|---|---|---|
| 简单随机样本 | $X_1,X_2,\ldots,X_n$ 独立同分布，且与总体 $X$ 同分布 | 数理统计默认前提 |
| 样本均值 | $\overline X=\dfrac1n\sum_{i=1}^nX_i$ | 估计总体均值 |
| 样本方差 | $S^2=\dfrac1{n-1}\sum_{i=1}^n(X_i-\overline X)^2$ | 分母是 $n-1$ |
| 样本标准差 | $S=\sqrt{S^2}$ | 样本方差开方 |
| 样本 $k$ 阶原点矩 | $A_k=\dfrac1n\sum_{i=1}^nX_i^k$ | 估计 $E(X^k)$ |
| 样本 $k$ 阶中心矩 | $B_k=\dfrac1n\sum_{i=1}^n(X_i-\overline X)^k$ | 估计中心矩 |
| 样本方差展开 | $\sum_{i=1}^n(X_i-\overline X)^2=(n-1)S^2$ | 判断 $\chi^2$ 高频 |

### 6.2 样本均值与样本方差的性质

| 类型 | 条件/对象 | 公式 | 实际意义 |
|---|---|---|---|
| 样本均值期望 | 总体 $E(X)=\mu$ | $E(\overline X)=E(X)=\mu$ | 样本均值无偏估计总体均值 |
| 样本均值方差 | 总体 $D(X)=\sigma^2$ | $D(\overline X)=\dfrac{D(X)}n=\dfrac{\sigma^2}n$ | 样本量越大，均值越稳定 |
| 样本方差期望 | 总体 $D(X)=\sigma^2$ | $E(S^2)=D(X)=\sigma^2$ | 样本方差无偏估计总体方差 |
| 正态总体样本方差方差 | $X\sim N(\mu,\sigma^2)$ | $D(S^2)=\dfrac{2\sigma^4}{n-1}$ | 正态总体下成立 |
| 样本均值分布 | $X\sim N(\mu,\sigma^2)$ | $\overline X\sim N(\mu,\dfrac{\sigma^2}{n})$ | 正态总体下精确成立 |

### 6.3 三个抽样分布

| 分布 | 构造 | 记号 | 期望/方差 | 说明 |
|---|---|---|---|---|
| $\chi^2$ 分布 | $X_i\sim N(0,1)$ 独立，$Y=\sum_{i=1}^nX_i^2$ | $Y\sim\chi^2(n)$ | $E(Y)=n,D(Y)=2n$ | 自由度为平方项个数 |
| $\chi^2$ 可加性 | $Y_1\sim\chi^2(m),Y_2\sim\chi^2(n)$ 独立 | $Y_1+Y_2\sim\chi^2(m+n)$ |  | 自由度相加 |
| $t$ 分布 | $X\sim N(0,1),Y\sim\chi^2(n)$ 独立 | $\dfrac{X}{\sqrt{Y/n}}\sim t(n)$ |  | 标准正态除以卡方均值根号 |
| $F$ 分布 | $Y_1\sim\chi^2(n_1),Y_2\sim\chi^2(n_2)$ 独立 | $\dfrac{Y_1/n_1}{Y_2/n_2}\sim F(n_1,n_2)$ |  | 分子自由度在前 |
| $t$ 与 $F$ | $T\sim t(n)$ | $T^2\sim F(1,n)$ |  | 常用于转化 |
| $F$ 倒数性质 | $F\sim F(n_1,n_2)$ | $\dfrac1F\sim F(n_2,n_1)$ |  | 自由度交换 |

### 6.4 正态总体下的抽样分布

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 样本均值正态分布 | $X_i\sim N(\mu,\sigma^2)$ | $\overline X\sim N(\mu,\dfrac{\sigma^2}{n})$ | 精确分布 |
| 样本均值标准化 | 同上 | $\dfrac{\overline X-\mu}{\sigma/\sqrt n}\sim N(0,1)$ | $\sigma$ 已知时常用 |
| 总体均值平方型 | 同上 | $\dfrac{n(\overline X-\mu)^2}{\sigma^2}\sim\chi^2(1)$ | 标准正态平方 |
| 围绕总体均值平方和 | 同上 | $\dfrac{\sum_{i=1}^n(X_i-\mu)^2}{\sigma^2}\sim\chi^2(n)$ | 自由度 $n$ |
| 围绕样本均值平方和 | 同上 | $\dfrac{\sum_{i=1}^n(X_i-\overline X)^2}{\sigma^2}\sim\chi^2(n-1)$ | 自由度 $n-1$ |
| 样本方差卡方 | 同上 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | 上式等价形式 |
| 均值与方差独立 | 正态总体 | $\overline X$ 与 $S^2$ 相互独立 | 正态总体特有 |
| $\sigma$ 未知的 $t$ 统计量 | 正态总体 | $\dfrac{\overline X-\mu}{S/\sqrt n}\sim t(n-1)$ | 用 $S$ 替代 $\sigma$ |

### 6.5 两个正态总体的抽样分布

| 类型 | 条件/对象 | 公式 | 说明 |
|---|---|---|---|
| 两样本均值差 | 独立正态总体 | $\overline X-\overline Y\sim N(\mu_1-\mu_2,\dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2})$ | 两总体均值比较 |
| 均值差标准化 | $\sigma_1^2,\sigma_2^2$ 已知 | $\dfrac{(\overline X-\overline Y)-(\mu_1-\mu_2)}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}\sim N(0,1)$ | 已知方差 |
| 方差比 | 两独立正态总体 | $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1,n_2-1)$ | 分子自由度 $n_1-1$ |
| 合并样本方差 | $\sigma_1^2=\sigma_2^2$ | $S_w^2=\dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$ | 方差相等时 |
| 方差相等均值差 $t$ | $\sigma_1^2=\sigma_2^2$ | $\dfrac{(\overline X-\overline Y)-(\mu_1-\mu_2)}{S_w\sqrt{1/n_1+1/n_2}}\sim t(n_1+n_2-2)$ | 双样本 $t$ |

### 6.6 判断分布的常用拆解表

| 看到的式子 | 应拆成 | 分布 |
|---|---|---|
| $\sum_{i=1}^n(X_i-\mu)^2$ | 除以 $\sigma^2$ | $\chi^2(n)$ |
| $\sum_{i=1}^n(X_i-\overline X)^2$ | 除以 $\sigma^2$ | $\chi^2(n-1)$ |
| $(\overline X-\mu)^2$ | 乘 $\dfrac{n}{\sigma^2}$ | $\chi^2(1)$ |
| $\dfrac{\overline X-\mu}{S/\sqrt n}$ | 标准正态 / 独立卡方根 | $t(n-1)$ |
| $\dfrac{\chi^2(m)/m}{\chi^2(n)/n}$ | 两个独立卡方比 | $F(m,n)$ |
| $X_1-X_2$，$X_i\sim N(\mu,\sigma^2)$ 独立 | $E=0,D=2\sigma^2$ | $N(0,2\sigma^2)$ |
| $2X_3-X_4-X_5$ | $E=0,D=6\sigma^2$ | $N(0,6\sigma^2)$ |
| $\dfrac{(X_1-X_2)^2}{2\sigma^2}+\dfrac{(2X_3-X_4-X_5)^2}{6\sigma^2}$ | 两个独立标准正态平方相加 | $\chi^2(2)$ |
