这道题属于大地测量学中的短距离坐标计算。

**前提说明与假设：**
点(1)的经度标记为“西经88度12分34.5秒”，点(2)标记为“西经88度13分0.4秒”。

为了达到精确到 **0.1米** 的要求，不能将地球简单看作正圆球体，而必须使用 **WGS84 椭球体模型**。

---

### 一、 公式推导与计算原理

对于两点距离较近（相距仅几百米）的情况，南北方向和东西方向的距离可以通过将地球表面近似为**局部参考椭球面的曲率圆**来计算。

#### 1. WGS84 椭球体基本参数
*   长半轴 $a = 6378137.0$ 米
*   短半轴 $b = 6356752.3142$ 米
*   第一偏心率平方 $e^2 = \frac{a^2 - b^2}{a^2} \approx 0.00669437999$

#### 2. 坐标转换与差值计算
将度分秒(DMS)转化为十进制度(DD)，然后再转化为弧度(Radian)。
*   **点 1：** $Lon_1 = 88^\circ 12' 34.5''$ , $Lat_1 = 40^\circ 4' 21.2''$
*   **点 2：** $Lon_2 = 88^\circ 13' 0.4''$ , $Lat_2 = 40^\circ 4' 8.1''$

计算经纬度差值（取绝对值）：
*   纬度差 $\Delta Lat = |40^\circ 4' 21.2'' - 40^\circ 4' 8.1''| = 13.1''$
*   经度差 $\Delta Lon = |88^\circ 12' 34.5'' - 88^\circ 13' 0.4''| = 25.9''$

计算两点的平均纬度 $Lat_m$（用于确定该局部的曲率半径）：
*   $Lat_m = \frac{Lat_1 + Lat_2}{2} = 40^\circ 4' 14.65'' \approx 40.070736^\circ$

#### 3. 计算局部曲率半径
在平均纬度 $Lat_m$ 处：
*   **子午圈曲率半径 $M$**（南北方向的半径）：
    $$M = \frac{a(1 - e^2)}{(1 - e^2 \sin^2(Lat_m))^{3/2}}$$
*   **卯酉圈曲率半径 $N$**（用于计算东西方向平行圈半径）：
    $$N = \frac{a}{\sqrt{1 - e^2 \sin^2(Lat_m)}}$$

#### 4. 距离计算
*   **南北方向距离 ($D_{NS}$)**：沿子午线的弧长。
    $$D_{NS} = M \times \Delta Lat_{rad}$$
*   **东西方向距离 ($D_{EW}$)**：沿平均纬度平行圈的弧长。平行圈的实际半径为 $R_p = N \cos(Lat_m)$。
    $$D_{EW} = N \times \cos(Lat_m) \times \Delta Lon_{rad}$$

*(注：$\Delta Lat_{rad}$ 和 $\Delta Lon_{rad}$ 为用弧度表示的经纬度差)*

---

### 二、 Python 代码求解

下面是完整的 Python 脚本，包含了上述推导过程的精确计算：

```python
import math

def dms_to_rad(degrees, minutes, seconds):
    """将度分秒转换为弧度"""
    decimal_degrees = degrees + minutes / 60.0 + seconds / 3600.0
    return math.radians(decimal_degrees)

# --- 1. 输入数据 ---
# 点 1
lon1_d, lon1_m, lon1_s = 88, 12, 34.5
lat1_d, lat1_m, lat1_s = 40, 4, 21.2

# 点 2
lon2_d, lon2_m, lon2_s = 88, 13, 0.4
lat2_d, lat2_m, lat2_s = 40, 4, 8.1

# --- 2. 转换为十进制和弧度 ---
lon1 = lon1_d + lon1_m/60 + lon1_s/3600
lat1 = lat1_d + lat1_m/60 + lat1_s/3600

lon2 = lon2_d + lon2_m/60 + lon2_s/3600
lat2 = lat2_d + lat2_m/60 + lat2_s/3600

# 计算差值的弧度
delta_lat_rad = math.radians(abs(lat1 - lat2))
delta_lon_rad = math.radians(abs(lon1 - lon2))

# 计算平均纬度 (弧度)
lat_m_rad = math.radians((lat1 + lat2) / 2.0)

# --- 3. WGS84 椭球体常数 ---
a = 6378137.0  # 长半轴 (米)
b = 6356752.314245  # 短半轴 (米)
e_sq = (a**2 - b**2) / a**2  # 第一偏心率平方

# --- 4. 计算曲率半径 ---
sin_lat_m = math.sin(lat_m_rad)
W_sq = 1 - e_sq * (sin_lat_m ** 2)

# 子午圈曲率半径 M (南北方向)
M = (a * (1 - e_sq)) / (math.pow(W_sq, 1.5))

# 卯酉圈曲率半径 N (东西方向相关)
N = a / math.sqrt(W_sq)

# --- 5. 计算距离 ---
# 南北方向距离
distance_ns = M * delta_lat_rad

# 东西方向距离
distance_ew = N * math.cos(lat_m_rad) * delta_lon_rad

# --- 6. 输出结果 ---
print(f"两点经度差: {abs(lon1 - lon2)*3600:.1f} 秒")
print(f"两点纬度差: {abs(lat1 - lat2)*3600:.1f} 秒")
print("-" * 30)
print(f"东西方向距离: {distance_ew:.1f} 米")
print(f"南北方向距离: {distance_ns:.1f} 米")
```

### 三、 运行结果解析

运行上述 Python 代码，计算结果如下：
两点经度差: 25.9 秒
两点纬度差: 13.1 秒
东西方向距离: 613.7 米
南北方向距离: 404.0 米

**结论：**
两点之间在**东西方向的距离为 613.7 米**，在**南北方向的距离为 404.0 米**（精度已控制在 0.1 米）。
