推导“含参变量的变限积分求导公式”（通常称为**通用莱布尼茨公式**）是高等数学中的一个重要知识点。

我们要证明的是：
若 $F(x) = \int_{\alpha(x)}^{\beta(x)} f(x, t) \, dt$，则其导数为：
$$F'(x) = f(x, \beta(x)) \cdot \beta'(x) - f(x, \alpha(x)) \cdot \alpha'(x) + \int_{\alpha(x)}^{\beta(x)} \frac{\partial f(x, t)}{\partial x} \, dt$$

### 推导步骤：

#### 1. 构造辅助函数
为了把变量 $x$ 的不同影响路径拆开，我们设一个三元函数 $\Phi(u, v, w)$：
$$\Phi(u, v, w) = \int_{u}^{v} f(w, t) \, dt$$
在这个函数中：
*   $u$ 代表积分下限。
*   $v$ 代表积分上限。
*   $w$ 代表被积函数中的参变量。

那么，原函数可以看作是：
$$F(x) = \Phi(\alpha(x), \beta(x), x)$$

#### 2. 利用全微分求导公式（链式法则）
根据复合函数求导法则，$F'(x)$ 等于 $\Phi$ 对各个自变量的偏导数与自变量对 $x$ 导数的乘积之和：
$$\frac{dF}{dx} = \frac{\partial \Phi}{\partial u} \cdot \frac{du}{dx} + \frac{\partial \Phi}{\partial v} \cdot \frac{dv}{dx} + \frac{\partial \Phi}{\partial w} \cdot \frac{dw}{dx}$$

我们将这三部分分别计算出来：

#### 3. 计算各个偏导数

*   **第一部分：对上限 $v$ 求偏导**
    根据**牛顿-莱布尼茨公式（变上限定积分求导定理）**：
    $$\frac{\partial \Phi}{\partial v} = \frac{\partial}{\partial v} \int_{u}^{v} f(w, t) \, dt = f(w, v)$$
    代入 $v = \beta(x), w = x$，得到：$f(x, \beta(x))$。

*   **第二部分：对下限 $u$ 求偏导**
    利用积分性质 $\int_u^v = -\int_v^u$：
    $$\frac{\partial \Phi}{\partial u} = \frac{\partial}{\partial u} \left( -\int_{v}^{u} f(w, t) \, dt \right) = -f(w, u)$$
    代入 $u = \alpha(x), w = x$，得到：$-f(x, \alpha(x))$。

*   **第三部分：对参变量 $w$ 求偏导**
    这是**积分符号内取微分法则**。在积分限暂时固定（视为常数）的情况下：
    $$\frac{\partial \Phi}{\partial w} = \frac{\partial}{\partial w} \int_{u}^{v} f(w, t) \, dt = \int_{u}^{v} \frac{\partial f(w, t)}{\partial w} \, dt$$
    代入 $w = x$，得到：$\int_{\alpha(x)}^{\beta(x)} \frac{\partial f(x, t)}{\partial x} \, dt$。

#### 4. 组合公式
将上述三部分以及 $\frac{du}{dx}=\alpha'(x), \frac{dv}{dx}=\beta'(x), \frac{dw}{dx}=1$ 全部代入链式法则公式中：
$$F'(x) = \underbrace{f(x, \beta(x)) \cdot \beta'(x)}_{\text{上限变动的影响}} - \underbrace{f(x, \alpha(x)) \cdot \alpha'(x)}_{\text{下限变动的影响}} + \underbrace{\int_{\alpha(x)}^{\beta(x)} \frac{\partial f(x, t)}{\partial x} \, dt}_{\text{被积函数本身变动的影响}}$$

这道题的核心在于利用**换元法**简化积分结构，进而通过**递推关系**快速锁定结论。以下是精简后的解题步骤：

## 题目：
$$f(x) = \int_0^x \left( 1 + \frac{x-t}{1!} + \frac{(x-t)^2}{2!} + \dots + \frac{(x-t)^{n-1}}{(n-1)!} \right) e^{at} dt$$

### 1. 换元化简
设 $u = x - t$，则 $t = x - u, dt = -du$。代入原式并翻转上下限：
$$f(x) = e^{ax} \int_{0}^{x} P_{n-1}(u) e^{-au} du$$
其中 $P_{n-1}(u) = 1 + u + \frac{u^2}{2!} + \dots + \frac{u^{n-1}}{(n-1)!}$。

**核心思路：** 将 $x$ 从多项式中解脱出来，提到积分号外，变为乘积形式。

### 2. 建立递推关系
对 $f(x)$ 求导（利用乘积求导法则）：
$$f'(x) = a \underbrace{e^{ax} \int_{0}^{x} P_{n-1}(u) e^{-au} du}_{f(x)} + e^{ax} [P_{n-1}(x) e^{-ax}]$$
得到一阶递推式：
$$f'(x) = a f(x) + P_{n-1}(x)$$

继续求导，利用 $P_m'(x) = P_{m-1}(x)$ 的性质，得到高阶递推通式：
$$f^{(k)}(x) = a f^{(k-1)}(x) + P_{n-k}(x)$$

### 3. 归纳求解 $n$ 阶导数
当 $k=n$ 时，递推终止于：
$$f^{(n)}(x) = a f^{(n-1)}(x) + P_0(x) \quad (\text{其中 } P_0 = 1)$$

通过逐层回代递推式：
$$f^{(n)}(x) = a^n f(x) + \sum_{i=0}^{n-1} a^i P_i(x)$$
我们有：$f(x) = e^{ax} \int_{0}^{x} P_{n-1}(u) e^{-au} du$。

利用**分部积分法**处理 $\int P_{n-1}(u) e^{-au} du$：

由于 $P_{n-1}' = P_{n-2}, P_{n-2}' = P_{n-3} \dots P_0' = 0$，积分过程如下：
$$\int P_{n-1} e^{-au} du = P_{n-1} \left(\frac{e^{-au}}{-a}\right) - P_{n-2} \left(\frac{e^{-au}}{a^2}\right) + P_{n-3} \left(\frac{e^{-au}}{-a^3}\right) - \dots$$
整理得通项式：
$$\int P_{n-1}(u) e^{-au} du = -e^{-au} \sum_{j=1}^{n} \frac{P_{n-j}(u)}{a^j}$$

代入上限 $x$ 和下限 $0$（注意 $P_k(0)=1$）：
$$\int_{0}^{x} P_{n-1} e^{-au} du = \underbrace{-e^{-ax} \sum_{j=1}^{n} \frac{P_{n-j}(x)}{a^j}}_{\text{上限}} - \underbrace{\left( -1 \cdot \sum_{j=1}^{n} \frac{1}{a^j} \right)}_{\text{下限}}$$
将此结果代回 $f(x) = e^{ax} \cdot [\dots]$ 中：
$$f(x) = -\sum_{j=1}^{n} \frac{P_{n-j}(x)}{a^j} + e^{ax} \sum_{j=1}^{n} \frac{1}{a^j}$$

### 3. 执行抵消计算
将上面求出的 $f(x)$ 代入之前的递推合成式 $f^{(n)}(x) = a^n f(x) + \sum_{i=0}^{n-1} a^i P_i(x)$：

$$f^{(n)}(x) = a^n \left[ -\sum_{j=1}^{n} \frac{P_{n-j}(x)}{a^j} + e^{ax} \sum_{j=1}^{n} \frac{1}{a^j} \right] + \sum_{i=0}^{n-1} a^i P_i(x)$$

将 $a^n$ 乘进括号：
$$f^{(n)}(x) = \underbrace{-\sum_{j=1}^{n} a^{n-j} P_{n-j}(x)}_{\text{项 A}} + \underbrace{e^{ax} \sum_{j=1}^{n} a^{n-j}}_{\text{项 B}} + \underbrace{\sum_{i=0}^{n-1} a^i P_i(x)}_{\text{项 C}}$$

**观察项 A 和项 C：**
在项 A 中，令 $i = n-j$。当 $j=1 \to n$ 时，$i=n-1 \to 0$。
则项 A 变为：$-\sum_{i=0}^{n-1} a^i P_i(x)$。
这与项 C **完全相等但符号相反**，两者相加为 $0$。

### 4. 得出结论
剩下的只有项 B：
$$f^{(n)}(x) = e^{ax} \sum_{j=1}^{n} a^{n-j} = e^{ax} (a^{n-1} + a^{n-2} + \dots + 1)$$


通过计算常数项系数（或令 $x=0$ 观察系数和）：
$$f^{(n)}(x) = \left( \sum_{i=0}^{n-1} a^i \right) e^{ax}$$

若 $a \neq 1$，结果为：
$$f^{(n)}(x) = \frac{a^n - 1}{a - 1} e^{ax}$$
若 $a = 1$，结果为：
$$f^{(n)}(x) = n e^x$$




### 例题2
设数列{$x_n$}满足$x_1 = a > 1$,且满足递推$x_{n+1} = 1+ln{(\frac{x_n^2}{1+ln x_n})}$,n=1,2,3...
求证{$x_n$}收敛，并求出极限值。

设 $f(x) = 1 + 2\ln x - \ln(1 + \ln x)$。由 $x_1 = a > 1$ 知 $\ln x_1 > 0$。

首先证明 $x_n > 1$ 对一切 $n \in \mathbb{N}$ 均成立。设 $t = \ln x$，考虑函数 $g(t) = 1 + 2t - \ln(1 + t)$。由于 $g'(t) = 2 - \frac{1}{1+t} = \frac{2t+1}{1+t}$，在 $t > 0$ 时 $g'(t) > 0$，故 $g(t)$ 单调递增。从而 $g(t) > g(0) = 1$，即当 $x > 1$ 时 $f(x) > 1$。由数学归纳法可知，全体项 $x_n > 1$。

接着证明 $\{x_n\}$ 单调递减。令 $h(x) = f(x) - x$，代换 $t = \ln x > 0$ 得 $H(t) = 1 + 2t - \ln(1+t) - e^t$。对 $t$ 求导得 $H'(t) = 2 - \frac{1}{1+t} - e^t$，$H''(t) = \frac{1}{(1+t)^2} - e^t$。当 $t > 0$ 时，$\frac{1}{(1+t)^2} < 1$ 且 $e^t > 1$，故 $H''(t) < 0$，即 $H'(t)$ 在 $(0, +\infty)$ 单调递减。因 $H'(0) = 0$，故当 $t > 0$ 时 $H'(t) < 0$。又因 $H(0) = 0$，故当 $t > 0$ 时 $H(t) < 0$，即 $f(x) < x$。由此得 $x_{n+1} < x_n$，数列 $\{x_n\}$ 单调递减。

综上，数列 $\{x_n\}$ 单调递减且有下界 1，由单调有界准则知极限存在。设 $\lim_{n \to \infty} x_n = L$，则 $L \ge 1$。在递推式两端取极限得：
$$L = 1 + 2\ln L - \ln(1 + \ln L)$$
即 $h(L) = 0$。由前述对 $H(t)$ 的分析可知，$H(t) = 0$ 在 $t \ge 0$ 时有且仅有唯一解 $t = 0$。因此 $\ln L = 0$，解得 $L = 1$。

所以，数列 $\{x_n\}$ 收敛，其极限值为 1。
